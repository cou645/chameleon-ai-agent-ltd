Accessibility statement

How accessible the Chameleon AI website and software are, and how to tell us about a problem.

🎯 Target: WCAG 2.1 AA 🖥️ App: EN 301 549

Statement prepared: 2 September 2026  ·  Last reviewed: 2 September 2026  ·  Last tested: 2 September 2026

1. Scope

This statement applies to the website at chameleon-ai-agent-ltd.net and its subdomains, published by CHAMELEON-AI-AGENT LTD (company no. 17147789). It also describes the accessibility position of the Chameleon Accounting desktop and mobile software, which is in development.

2. Our commitment

We want the website and software to be usable by as many people as possible. That means you should be able to:

  • navigate the website with a keyboard alone;
  • use it with a screen reader;
  • change colours and contrast, and zoom to 400% without content being lost;
  • read text against sufficiently contrasting backgrounds.

3. How accessible this website is

We believe the website is largely compliant with the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. In particular:

  • all text meets the AA contrast minimum of 4.5:1 (3:1 for large text and interface components);
  • every page has a "skip to main content" link, a labelled main-navigation region and a <main> landmark;
  • keyboard focus is always visible;
  • the site is built from semantic HTML with a page language set, and images have text alternatives;
  • animation is limited to a single small indicator, which is suppressed when the operating system's "reduce motion" setting is on.

4. Known issues (non-accessible content)

  • Mobile navigation. On narrow phone screens the main navigation menu is hidden and only the links in the page footer remain. All destinations are still reachable, but not from the top of the page. We plan to add an in-page menu.
  • Language menu. The language switcher can be opened and closed with the keyboard and its items are standard links, but it does not yet support arrow-key navigation or closing with the Esc key.
  • Independent testing. The website has been checked by calculation (contrast) and code review. It has not yet been through an automated testing tool or a full assistive-technology test by a third party.

None of these prevents access to information or functionality; they are ease-of-use gaps we are working to close.

5. The Chameleon Accounting software

The standalone Chameleon Accounting application (for phone, tablet and desktop) is being rebuilt. It is being developed to meet EN 301 549, the offline equivalent of WCAG 2.1 AA, with a per-screen accessibility checklist covering keyboard operation, screen-reader labelling, text scaling, contrast, reflow, form-error identification and target size. It will be independently assessed, and this statement updated, before it is released for production use.

6. Feedback and reporting a problem

If you find a part of the website or software you cannot use, or you need information in a different format, contact us and tell us what you were trying to do:

stemsee@chameleon-ai-agent-ltd.net

We aim to reply within five working days. Where we can, we will provide the information you need in an accessible format.

7. Enforcement

If you are not happy with how we respond to your complaint, in the UK the Equality and Human Rights Commission (EHRC) is responsible for enforcing the Equality Act 2010. You can contact the Equality Advisory and Support Service (EASS) at equalityadvisoryservice.com.

8. Technical information

CHAMELEON-AI-AGENT LTD is committed to making its website accessible. This website is partially compliant with the Web Content Accessibility Guidelines 2.1 Level AA, because of the issues listed in section 4.

How we tested

The website was last tested on 2 September 2026. Testing was carried out internally: WCAG 2.1 AA colour-contrast ratios were verified by calculation for every text/background pair, and pages were reviewed against the AA success criteria for keyboard operation, focus visibility, landmarks, page structure, language, text alternatives and reduced motion. Automated-tool and assistive-technology testing is planned.

9. What we are doing to improve accessibility

  • Add an accessible in-page navigation menu for small screens.
  • Complete keyboard support for the language menu (arrow keys, Esc).
  • Run an automated accessibility scan on every release and fix any AA finding.
  • Commission an independent WCAG 2.1 AA / EN 301 549 assessment of the website and the Chameleon Accounting app, and publish the result here.
