Common questions

Can I try it?

Not yet on general release. Email us for a demo and to be told when it opens up.

Does it work offline?

Mostly. The editor, accounting, presenter and driver tools all run locally. AI features need internet for a cloud provider — or work offline with a local model through Ollama or LM Studio.

Which platforms?

Linux is the main platform; Windows and macOS are supported. The phone companion is Android and pairs with the desktop over your own private network.
