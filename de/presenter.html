Chamäleon-Moderator

Präsentationen, die bewegen. Ziehen Sie Folien, PDFs, Videos, einen Live-Bildschirm Ihres Telefons oder eine Webcam hinein – animieren Sie alles entlang einer Zeitachse und steuern Sie die gesamte Show von Ihrem Telefon aus.

🎬 Timeline-Animation 📱 Telefon-Fernbedienung, keine Einrichtung 🖇 Öffnet ClassIn- & Xournal++-Dateien 🙋 Live-Zuschauer-Einreichungen 🤖 Optionale KI-Regieanweisung

Sehen Sie es laufen

In dieser Aufnahme übernimmt eine KI den Regiestuhl – sie animiert Objekte und wechselt Layouts live, ohne dass jemand an der Tastatur sitzt. Jedes Steuerelement, das sie verwendet, kannst du selbst aus der App oder von deinem Telefon aus bedienen.

Was Sie damit machen können

Eine Bühne, die du komponierst, kein Stapel flacher Folien

🗂️

Lege etwas auf eine Folie

Bilder, Text, PDFs, Video, Live-Webseiten, ein gespiegelter Android-Bildschirm, ein Webcam-Feed, ein gemeinsames Zeichenbrett. Jedes davon ist ein Objekt, das du platzierst, in der Größe änderst und eigenständig bewegst – gestalte den Bildschirm so, wie du ihn möchtest.

🎬

Entlang einer Zeitleiste animieren

Verleihen Sie jedem Objekt einen Eingang, einen Ausgang oder einen handgezeichneten Bewegungspfad. Nummerierte Hinweise führen die Show Schlag für Schlag voran. Ein Klick fügt einen fertigen Zeitplan für einen 5-minütigen Pitch, eine 50-minütige Vorlesung oder einen 90-minütigen Workshop ein.

🖇️

Öffnen Sie die Dateien, die Sie bereits haben

ClassIn .edb Tafeln und Xournal++ .xop Notizen – vom Desktop oder der mobilen Xournal++-App – werden direkt importiert: Jede Seite und jeder Strich wird zu einem Objekt, das du bearbeiten und animieren kannst. PowerPoint, Keynote, Word und Markdown kommen über den universellen Dokumentimport herein.

💾

Eine Datei, viele Versionen

Ein Projekt wird als einzelne Datei gespeichert .capt Datei, die alle deine Medien sowie bis zu zehn benannte Zeitachsen enthält – der vollständige Vortrag, ein Highlight-Schnitt und eine Q&A-Reihenfolge können alle in einer Datei leben, die du einem Kollegen per E-Mail sendest.

📱

Führen Sie die Show von Ihrem Telefon aus

Die Kameleon Remote Android-App findet Ihren Computer automatisch über WLAN oder USB – nichts muss eingegeben werden. Sie erhalten eine Live-Miniaturansicht genau dessen, was das Publikum sieht, vorherige/nächste Folie, Wiedergabe/Pause/Stopp, einen Laserpointer-Spotlight sowie die Möglichkeit, direkt auf die Live-Folie zu zeichnen.

🙋

Lassen Sie den Raum teilnehmen

Schalten Sie einen Slot in den Publikumsmodus und Personen senden ein Bild oder eine schriftliche Antwort von ihren eigenen Telefonen. Jede Antwort wartet in einer Ablage – Sie genehmigen, halten oder lehnen sie ab, bevor sie auf den Bildschirm gelangt.

🤖

Übergib es einer KI — wenn du willst

Markieren Sie Zeitabschnitte der Timeline als KI-Segmente: Während einer Pause choreografiert die KI sanft, was auf dem Bildschirm zu sehen ist. Oder lassen Sie sie den gesamten Vortrag leiten, wie im Video oben. Völlig optional – die App funktioniert auch vollständig ohne diese Funktion.

🖥️

Sieht auf jedem Bildschirm richtig aus

Die Bühne skaliert auf das Display, auf dem sie angezeigt wird, sodass ein auf einem Laptop erstellter Vortrag auf einem 4K-Projektor identisch aussieht. Kein Umbrechen, keine Überraschungen im Raum.

Funktioniert mit Chameleon Classroom

Die beiden Apps teilen sich ein Dateiformat und einen Player.

🖇️

Gleiche Import-Engine

Der .edb Und .xop importiert funktioniert identisch in Chameleon Classroom, sodass Unterrichtsmaterial unverändert zwischen den beiden Apps übertragen werden kann.

▶️

Eingebauter Player

Der Classroom führt Kameleon Presenter in seinem unteren Bereich im Nur-Wiedergabe-Modus aus — präsentieren Sie eine .capt Deck innerhalb einer Live-Lektion, ohne das Klassenzimmer zu verlassen.

🤖

Ein KI im Unterrichtschat

Der Kursraum fügt einen KI-Chat-Teilnehmer hinzu, den du wie jeden anderen Schüler ansprichst. Ein An KI senden Die Schaltfläche in sowohl der Desktop- als auch der Android-App bringt sie jederzeit ins Gespräch, wann immer du möchtest.
