Chamäleon-KI-IDE

Ein Code-Editor, bei dem die KI die Arbeit erledigt – sie liest Ihre Dateien, nimmt die Änderungen vor, führt die Befehle aus und prüft das Ergebnis. Sie überprüfen und genehmigen.

🧠 AI bearbeitet Ihren Code direkt 🎙️ Stimme ein, gesprochene Antworten 🔀 Sehen Sie sich einen Unterschied an, bevor Sie zustimmen 🔌 Neun KI-Anbieter, jederzeit wechselbar 🔒 Läuft lokal, die Schlüssel bleiben bei Ihnen

Was macht es anders?

Die meisten KI-Redakteure schlagen vor. Dieser bedient den Editor.

🤖

Die KI nimmt die Änderungen vor

Es liest eine Datei einmal und nimmt dann so viele präzise Änderungen wie nötig vor, ohne sie erneut zu lesen. Bearbeitungen zielen auf den exakten Text und nicht auf Zeilennummern ab, sodass sie bei Änderungen in der Datei nicht verschoben werden. Neue Dateien werden als Ganzes geschrieben – mit einer automatischen Sicherung aller ersetzten Dateien.

💻

Es führt Befehle aus und liest die Ergebnisse

Die KI führt Shell-Befehle im integrierten Terminal aus, wartet auf jedes Ergebnis, prüft den Exit-Code und entscheidet, was als nächstes zu tun ist. Echte Arbeit in einer Live-Shell – keine Copy-Paste-Schnipsel.

🛡️

Standardmäßig sicher

Alles, was die KI aus einer Datei, einem Terminal oder einer Webseite liest, wird als Daten abgegrenzt, niemals als Anweisungen – eine schädliche Datei kann die Sitzung nicht kapern. Jede vorgenommene Änderung wird mit einem Zeitstempel und einer Sitzungs-ID protokolliert, sodass Sie einen vollständigen Verlauf der Ereignisse haben.

🔀

Überprüfen Sie es, bevor Sie es akzeptieren

Ein Klick zeigt einen farbcodierten Unterschied der KI-Änderungen im Vergleich zu Ihrem letzten Speicherstand. Akzeptieren Sie sie, bearbeiten Sie sie weiter oder machen Sie einen Rückzieher.

🎙️

Freihändig

Diktieren Sie eine Frage oder eine ganze Aufforderung mit der Sprach-zu-Text-Funktion auf dem Gerät und lassen Sie sich die Antworten mit natürlicher Stimme vorlesen. Nichts geht an einen Cloud-Transkriptionsdienst.

🔌

Bringen Sie Ihre eigene KI mit

DeepSeek, OpenAI, Claude, Groq, Mistral, Kimi – wechseln Sie mitten in einem Projekt den Anbieter. Führen Sie ein Modell lokal über Ollama oder LM Studio aus, völlig kostenlos. Claude Code wird als Live-Prozess direkt im Terminal ausgeführt.

🧩

Stapelbare Arbeitsmodi

Aktivieren Sie die Modi, die Sie benötigen – Codereparatur, wissenschaftliches Schreiben, einfacher Chat – und kombinieren Sie sie. Bevor Sie etwas versenden, wird ein Kostenvoranschlag für die laufenden Kosten angezeigt.

🗂️

Darunter ein echter Editor

Bearbeiten mehrerer Registerkarten mit Rückgängigmachen pro Registerkarte und Syntaxhervorhebung, eine Projektdateistruktur und ein Streaming-Chat, der dafür sorgt, dass das Fenster reagiert, während Befehle im Hintergrund ausgeführt werden.

Senden Sie Routen und Haltestellen an Fahrer

Übertragen Sie eine Routendatei direkt von der IDE auf das Telefon eines Fahrers – sie wird sofort auf dessen Live-Karte geladen. Punktesätze (Tankstellen, Gefahrenstellen, Lieferadressen) können einzeln versendet werden und werden als farbcodierte Pins angezeigt. Keine separate Versandsoftware.
