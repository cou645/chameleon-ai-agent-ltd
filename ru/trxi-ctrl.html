TrXi-Ctrl

Бесплатное удалённое управление вашим рабочим столом Linux — Bluetooth, брандмауэр, аудио, медиа, окна, терминал, общий доступ к экрану, общий буфер обмена и чат с ИИ, с вашего телефона или с другого компьютера — а также, на рутированных телефонах, VPN-точка доступа и USB-накопитель. Создано для Debian Trixie; работает и на большинстве других рабочих столов Linux с X11.

Настольные приложения

TrXi-Ctrl теперь работает на Windows, macOS и Linux, а также на телефонах. Управляйте своим компьютером с Linux с ноутбука: те же экраны, с настоящей мышью и клавиатурой.

🖱️

Удалённый рабочий стол с мышью и клавиатурой

Перемещайте, щёлкайте (левой, средней, правой), перетаскивайте и прокручивайте удалённый экран своей мышью; печатайте и используйте сочетания клавиш, например Ctrl+C, на своей клавиатуре. Сенсорное управление на телефонах не изменилось.

🔇

Звук вместе с изображением

Удалённый рабочий стол воспроизводит звук компьютера вместе с экраном, с кнопкой отключения звука на вкладке «Рабочий стол».

🖼️

Сопряжение по картинке или коду

Не рядом с компьютером? Кто-то рядом может отправить вам QR-код сопряжения по электронной почте — откройте картинку в сканере приложения (значок изображения). Компьютеры без камеры вводят код сопряжения вручную.

🛡️

Устройства и белый список

На странице администратора шлюза перечислены все устройства, которые подключались, и указано, в сети ли они, а также можно разрешить доступ только отмеченным устройствам — по имени Tailscale или, в вашей домашней сети, по MAC-адресу.

🎛️

Менеджер шлюза

Небольшая настольная панель для запуска, остановки и перезапуска службы шлюза, отображения, сохранения или копирования QR-кода сопряжения и просмотра журнала шлюза.

Что это делает

Одно приложение на телефоне, один демон-шлюз на вашем рабочем столе

Система и слои

Живая статистика ЦП/памяти/температуры и переключение слоёв AUFS прямо с рабочего стола.

📶

Сеть и Wi-Fi

Интерфейсы, адреса, сканирование и подключение Wi-Fi — включая обнаружение узлов Tailscale для автоматического поиска вашего шлюза.

🔵

Bluetooth

Питание, режим обнаружения/сопряжения, сканирование, сопряжение, подключение, доверие, удаление — полный контроль над адаптером.

🛡️

Брандмауэр

Просматривайте и редактируйте правила и цепочки iptables, применяйте пресеты с вашего телефона.

🔊

Аудио

Громкость, mute, список sink — и трансляция аудиовыхода рабочего стола на динамик вашего телефона через WebRTC.

🎬

Медиа

Настоящие play/pause/seek/volume для Chameleon Media Center и плееров на базе MPV, через собственный IPC-сокет mpv — а не просто статический список файлов.

📺

СМС Live

Смотрите Chameleon Media Centerпрямой эфир на вашем телефоне — выберите Low latency (MPEG-TS) или Smooth (HLS) для слабых соединений — узнайте, идёт ли эфир, его источник и сколько зрителей, и скопируйте ссылку, чтобы любой мог смотреть в браузере.

🪟

Windows и рабочие столы

Список, фокус, закрытие, сворачивание, разворачивание, мозаика окон и переключение виртуальных рабочих столов.

📲

Удалённый рабочий стол

Полный обмен экраном через WebRTC со звуком ПК — смотрите и управляйте своим рабочим столом из любой точки вашей сети. На телефоне касания управляют мышью, а экранная панель отправляет текст; в приложениях для Windows, macOS и Linux ваши собственная мышь и клавиатура работают напрямую. Клики и нажатия клавиш отображаются на рабочем столе почти мгновенно; любая заметная задержка связана с обновлением экрана, а не с вашим вводом.

📋

Общий буфер обмена

ПК — это хаб: каждый телефон отправляет свой буфер обмена туда — прямо в собственный буфер обмена ПК, готовый к вставке — а экран Clipboard перечисляет последнюю запись каждого устройства. Нажмите на одну, чтобы скопировать её на этот телефон. В фоновом режиме ничего не читается и не записывается в буфер обмена вашего телефона, только когда вы нажимаете.

Рутованные телефоны

Два дополнительных экрана появляются автоматически, когда на телефоне есть root (Magisk)

🔐

VPN для точки доступа

Поделитесь выходным узлом Tailscale телефона со всеми устройствами в его Wi-Fi точке доступа — ноутбуки, телевизоры и консоли получают VPN без установки чего-либо. Маршрутизация восстанавливается автоматически при перезапуске точки доступа или Tailscale, а загрузочный скрипт может вернуть всё после перезагрузки. Создано для телефона, оставленного подключённым в качестве роутера: ограничение заряда, исключение Tailscale из оптимизации батареи и Always-on VPN.

💾

USB-накопитель

Подключите телефон к любому ПК, и он появится как USB-диск. Создайте образ диска до 256 ГБ за секунды — FAT32 (читается любой ОС), ext4 (без ограничения файлов в 4 ГБ) или загрузочный GPT-диск с разделом EFI, чтобы ноутбук мог загрузиться с телефона — затем поделитесь им для чтения-записи или только для чтения, либо откройте его на самом телефоне. Вы также можете передать ПК SD-карту телефона или USB-накопитель. ADB остаётся подключённым во время обмена.

Шлюз

trixie-gateway — сторона рабочего стола, единый самодостаточный бинарный файл

📦

Один бинарный файл, Python не нужен

Скачайте единый самодостаточный исполняемый файл — без Python, pip или venv на машине. Построен на aiohttp + aiortc, а исходный код по-прежнему на GitHub, если вы предпочитаете запускать из Python. Работает автономно или как служба systemd, прослушивая ваш адрес Tailscale/LAN.

🔌

~120 REST-эндпоинтов

Все функции телефонного приложения выше, плюс совместимый с OpenAI /v1/chat/completions который маршрутизирует к любому настроенному вами AI-провайдеру.

🧩

MCP-сервер включён

media_mcp_server.py предоставляет управление медиа (статус, воспроизведение, пауза, перемотка, громкость, открытие, просмотр) как инструменты MCP через stdio JSON-RPC — те же данные сессии и путь управления, что использует телефонное приложение, поэтому AI-агент и ваш телефон всегда видят одно и то же.

Установите приложение

Ни одна из сборок пока не подписана Apple или Microsoft, поэтому каждая система один раз спросит, доверяете ли вы ей

🤖

Андроид

Скачайте APK на телефон и откройте его. Android при первом запуске попросит разрешить установку из браузера или файлового менеджера — разрешите, затем нажмите «Установить». Большинству телефонов за последние десять лет нужен APK arm64; используйте armv7 только на старых 32-битных телефонах. Последующие обновления могут приходить прямо из gateway: Обновления вкладка.

🍏

iPhone и iPad

Сборка для iOS не подписана, поэтому устанавливается через sideload: установите С боковой загрузкой или Альтсторе на компьютере подключите iPhone, перетащите .ipa и войдите с любым Apple ID. Затем на iPhone: Настройки → Основные → VPN и управление устройством → доверьтесь своему Apple ID. С бесплатным Apple ID приложение нужно переустанавливать каждые 7 дней.

🪟

Windows 10/11

Распакуйте загрузку в любое место (например C:\Programs\TrXi-Ctrl) и запустите trxi_ctrl.exe. SmartScreen в первый раз скажет "Windows защитила ваш компьютер": Подробнее → Выполнить в любом случае. Держите файлы вместе — .exe нужны DLL и папка data рядом с ним.

🍎

macOS

Откройте .dmg и перетащите TrXi-Ctrl в Приложения. В первый раз щёлкните приложение правой кнопкой → Открыть → Открыть (двойной щелчок заблокирован, так как оно не нотаризовано). Если macOS всё ещё отказывается, Системные настройки → Конфиденциальность и безопасность → Всё равно открыть.

🐧

Линукс

Требуются GTK 3 и libmpv: в Debian/Ubuntu sudo apt install libgtk-3-0 libmpv2. Затем tar -xzf TrXi-Ctrl-1.1.0-linux.tar.gz и запустите ./bundle/trxi_ctrl. Держите bundle папку вместе.

🔗

Сопряжение с вашим компьютером

На рабочем столе Linux, где запущен шлюз, откройте http://localhost:8772/admin (или Gateway Manager). Телефоны и Mac: приложение → Настройки → значок сканера QR-кода → отсканируйте QR-код или нажмите на значок изображения, чтобы открыть картинку QR-кода, присланную вам по электронной почте. Windows и Linux: введите адрес шлюза и код сопряжения, показанный под QR-кодом. Код действует один раз и действителен 10 минут. Оба устройства должны находиться в одной сети Tailscale или локальной сети.

Установите шлюз

На машине с Debian Trixie (или совместимым Linux), которой вы хотите управлять

# Linux — автономный бинарный файл, больше ничего устанавливать не нужно curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # затем в мобильном приложении: Настройки → URL шлюза → http://<tailscale-или-LAN-IP-этой-машины>:8772 # или нажмите "Discover Peers", если вы оба в одной сети Tailscale

Предпочитаете Python? git clone https://github.com/cou645/trixie-gateway.git, затем pip install -r requirements.txt и python3 gateway.py --port 8772. Полная документация по установке, включая запуск в качестве службы systemd, находится в разделе репозитория README.md.

🧪 Тестовые сборки для Windows и macOS находятся на страница релизов (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). Они не подписаны, поэтому Windows SmartScreen скажет "неизвестный издатель" (Подробнее → Выполнить в любом случае), а macOS заблокирует первый запуск (правый клик → Открыть).
