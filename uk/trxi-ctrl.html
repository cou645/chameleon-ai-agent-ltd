TrXi-Ctrl

Безкоштовне віддалене керування вашим робочим столом Linux — Bluetooth, брандмауер, аудіо, медіа, вікна, термінал, спільний доступ до екрана, спільний буфер обміну та чат зі ШІ, усе з вашого телефону — а також на рутованих телефонах VPN-хотспот і USB-накопичувач. Створено для Debian Trixie; працює й на більшості інших робочих столів Linux з X11.

🆓 Безкоштовно та з відкритим кодом 🐧 Лише Linux / X11 🔌 14 екранів керування (+2 на рутованих телефонах) 🤖 Включено сервер MCP 🔒 Ваша мережа, без хмарного ретранслятора

Що це робить

Один застосунок на телефоні, один демон-шлюз на вашому робочому столі

🖥️

Система та шари

Жива статистика ЦП/пам'яті/температури та перемикання шарів AUFS прямо з робочого столу.

📶

Мережа та Wi-Fi

Інтерфейси, адреси, сканування та підключення Wi-Fi — включно з виявленням вузлів Tailscale для автоматичного пошуку вашого шлюзу.

🔵

Bluetooth

Живлення, режим виявлення/спарювання, сканування, спарювання, підключення, довіра, видалення — повний контроль над адаптером.

🛡️

Брандмауер

Переглядайте та редагуйте правила й ланцюжки iptables, застосовуйте пресети з вашого телефону.

🔊

Аудіо

Гучність, mute, список sink — і трансляція аудіовиходу робочого столу на динамік вашого телефона через WebRTC.

🎬

ЗМІ

Справжні play/pause/seek/volume для Chameleon Media Center та плеєрів на базі MPV, через власний IPC-сокет mpv — а не просто статичний список файлів.

📺

CMC Live

Дивіться Chameleon Media Centerпрямий ефір на вашому телефоні — виберіть Low latency (MPEG-TS) або Smooth (HLS) для слабких з'єднань — дізнайтеся, чи йде ефір, його джерело та скільки глядачів, і скопіюйте посилання, щоб будь-хто міг дивитися в браузері.

🪟

Windows і робочі столи

Список, фокус, закриття, згортання, розгортання, мозаїка вікон і перемикання віртуальних робочих столів.

📲

Віддалений робочий стіл

Повний обмін екраном через WebRTC з керуванням дотиком-як-мишею та введенням з клавіатури — дивіться та керуйте робочим столом звідусіль у вашій мережі. Повністю функціонально: дотики, перетягування та натискання клавіш, які ви надсилаєте, з'являються на робочому столі майже миттєво. Будь-яка помітна затримка — в оновленнях екрана, що надходять від робочого столу до вашого телефона, а не у вашому введенні.

📋

Спільний буфер обміну

ПК — це хаб: кожен телефон надсилає свій буфер обміну туди — прямо у власний буфер обміну ПК, готовий до вставлення — а екран Clipboard перелічує останній запис кожного пристрою. Торкніться одного, щоб скопіювати його на цей телефон. Нічого не читається та не записується у буфер обміну вашого телефона у фоновому режимі, лише коли ви торкаєтеся.

Термінал

AI-чат

Телефони з root

Два додаткові екрани з'являються автоматично, коли телефон має root (Magisk)

🔐

VPN для точки доступу

Поділіться вихідним вузлом Tailscale телефона з кожним пристроєм у його Wi-Fi точці доступу — ноутбуки, телевізори та консолі отримують VPN без встановлення чогось. Маршрутизація повторно застосовується автоматично, якщо точка доступу або Tailscale перезапускається, а завантажувальний скрипт може повернути все після перезавантаження. Створено для телефона, залишеного підключеним як роутер: обмеження заряду, виключення Tailscale з оптимізації батареї та Always-on VPN.

💾

USB-накопичувач

Підключіть телефон до будь-якого ПК, і він з'явиться як USB-диск. Створіть образ диска до 256 ГБ за секунди — FAT32 (читається будь-якою ОС), ext4 (без обмеження файлів у 4 ГБ) або завантажувальний GPT-диск із розділом EFI, щоб ноутбук міг завантажитися з телефона — потім поділіться ним для читання-запису або лише для читання, або відкрийте його на самому телефоні. Ви також можете передати ПК SD-карту телефона або USB-накопичувач. ADB залишається підключеним під час обміну.

Шлюз

trixie-gateway — сторона робочого столу, єдиний самодостатній бінарний файл

📦

Один бінарний файл, Python не потрібен

Завантажте єдиний самодостатній виконуваний файл — без Python, pip або venv на машині. Побудований на aiohttp + aiortc, а вихідний код досі на GitHub, якщо ви віддаєте перевагу запуску з Python. Працює автономно або як служба systemd, прослуховуючи вашу адресу Tailscale/LAN.

🔌

~120 REST-ендпоінтів

Усі функції застосунку телефона вище, плюс сумісний з OpenAI /v1/chat/completions який маршрутизує до будь-якого налаштованого вами AI-провайдера.

🧩

Сервер MCP включено

media_mcp_server.py надає керування медіа (статус, відтворення, пауза, перемотування, гучність, відкриття, перегляд) як інструменти MCP через stdio JSON-RPC — ті самі дані сесії та шлях керування, які використовує застосунок телефона, тож AI-агент і ваш телефон завжди бачать одне й те саме.

Встановіть шлюз

На машині з Debian Trixie (або сумісним Linux), якою ви хочете керувати

# Linux — автономний бінарний файл, більше нічого встановлювати не потрібно curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # потім у мобільному застосунку: Налаштування → URL шлюзу → http://<tailscale-або-LAN-IP-цієї-машини>:8772 # або торкніться "Discover Peers", якщо ви обидва в одній мережі Tailscale

Надаєте перевагу Python? git clone https://github.com/cou645/trixie-gateway.git, потім pip install -r requirements.txt і python3 gateway.py --port 8772. Повна документація зі встановлення, включно із запуском як служби systemd, є в репозиторії README.md.

🧪 Тестові збірки для Windows і macOS є на сторінка релізів (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). Вони не підписані, тому Windows SmartScreen скаже "невідомий видавець" (Докладніше → Виконати все одно), а macOS заблокує перший запуск (клацання правою кнопкою → Відкрити). Будь ласка, повідомте, що не працює.
