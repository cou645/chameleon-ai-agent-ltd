TrXi-Ctrl

Безкоштовне віддалене керування вашим робочим столом Linux — Bluetooth, брандмауер, аудіо, медіа, вікна, термінал, спільний доступ до екрана, спільний буфер обміну та чат зі ШІ, з вашого телефону або з іншого комп'ютера — а також, на рутованих телефонах, VPN-точка доступу та USB-накопичувач. Створено для Debian Trixie; працює й на більшості інших робочих столів Linux з X11.

Настільні застосунки

TrXi-Ctrl тепер працює на Windows, macOS і Linux, а також на телефонах. Керуйте своєю машиною Linux з ноутбука: ті самі екрани, зі справжньою мишею та клавіатурою.

🖱️

Віддалений робочий стіл з мишею та клавіатурою

Переміщайте, клацайте (лівою, середньою, правою), перетягуйте та прокручуйте віддалений екран мишею; вводьте текст і використовуйте сполучення клавіш, як-от Ctrl+C, на власній клавіатурі. Сенсорне керування на телефонах не змінилося.

🔇

Звук разом із зображенням

Віддалений робочий стіл відтворює звук комп'ютера разом із екраном, із кнопкою вимкнення звуку на вкладці «Робочий стіл».

🖼️

Сполучення за зображенням або кодом

Не біля комп'ютера? Хтось поруч може надіслати вам QR-код сполучення електронною поштою — відкрийте зображення в сканері застосунку (значок зображення). Комп'ютери без камери вводять код сполучення вручну.

🛡️

Пристрої та білий список

Сторінка адміністратора шлюзу перелічує кожен пристрій, який підключався, і чи він онлайн, а також дає змогу впускати лише позначені пристрої — за назвою Tailscale або, у вашій домашній мережі, за MAC-адресою.

🎛️

Менеджер шлюзу

Невелика настільна панель для запуску, зупинки та перезапуску служби шлюзу, показу, збереження чи копіювання QR-коду сполучення та перегляду журналу шлюзу.

Інтерфейси, адреси, сканування та підключення Wi-Fi — включно з виявленням вузлів Tailscale для автоматичного пошуку вашого шлюзу.

Bluetooth

Живлення, режим виявлення/спарювання, сканування, спарювання, підключення, довіра, видалення — повний контроль над адаптером.

Windows і робочі столи

Список, фокус, закриття, згортання, розгортання, мозаїка вікон і перемикання віртуальних робочих столів.

📲

Віддалений робочий стіл

Повний обмін екраном через WebRTC зі звуком ПК — дивіться та керуйте своїм робочим столом з будь-якого місця у вашій мережі. На телефоні дотики керують мишею, а екранна панель надсилає текст; у застосунках Windows, macOS і Linux ваші власні миша та клавіатура працюють безпосередньо. Клацання та натискання клавіш з'являються на робочому столі майже миттєво; будь-яка помітна затримка стосується оновлень екрана, що повертаються, а не вашого введення.

📋

Спільний буфер обміну

ПК — це хаб: кожен телефон надсилає свій буфер обміну туди — прямо у власний буфер обміну ПК, готовий до вставлення — а екран Clipboard перелічує останній запис кожного пристрою. Торкніться одного, щоб скопіювати його на цей телефон. Нічого не читається та не записується у буфер обміну вашого телефона у фоновому режимі, лише коли ви торкаєтеся.

Телефони з root

Два додаткові екрани з'являються автоматично, коли телефон має root (Magisk)

🔐

VPN для точки доступу

Поділіться вихідним вузлом Tailscale телефона з кожним пристроєм у його Wi-Fi точці доступу — ноутбуки, телевізори та консолі отримують VPN без встановлення чогось. Маршрутизація повторно застосовується автоматично, якщо точка доступу або Tailscale перезапускається, а завантажувальний скрипт може повернути все після перезавантаження. Створено для телефона, залишеного підключеним як роутер: обмеження заряду, виключення Tailscale з оптимізації батареї та Always-on VPN.

💾

USB-накопичувач

Підключіть телефон до будь-якого ПК, і він з'явиться як USB-диск. Створіть образ диска до 256 ГБ за секунди — FAT32 (читається будь-якою ОС), ext4 (без обмеження файлів у 4 ГБ) або завантажувальний GPT-диск із розділом EFI, щоб ноутбук міг завантажитися з телефона — потім поділіться ним для читання-запису або лише для читання, або відкрийте його на самому телефоні. Ви також можете передати ПК SD-карту телефона або USB-накопичувач. ADB залишається підключеним під час обміну.

Шлюз

trixie-gateway — сторона робочого столу, єдиний самодостатній бінарний файл

📦

Один бінарний файл, Python не потрібен

Завантажте єдиний самодостатній виконуваний файл — без Python, pip або venv на машині. Побудований на aiohttp + aiortc, а вихідний код досі на GitHub, якщо ви віддаєте перевагу запуску з Python. Працює автономно або як служба systemd, прослуховуючи вашу адресу Tailscale/LAN.

🔌

~120 REST-ендпоінтів

Усі функції застосунку телефона вище, плюс сумісний з OpenAI /v1/chat/completions який маршрутизує до будь-якого налаштованого вами AI-провайдера.

🧩

Сервер MCP включено

media_mcp_server.py надає керування медіа (статус, відтворення, пауза, перемотування, гучність, відкриття, перегляд) як інструменти MCP через stdio JSON-RPC — ті самі дані сесії та шлях керування, які використовує застосунок телефона, тож AI-агент і ваш телефон завжди бачать одне й те саме.

Встановіть застосунок

Жодна зі збірок поки не підписана Apple чи Microsoft, тому кожна система один раз запитає, чи довіряєте ви їй

🤖

Android

Завантажте APK на телефон і відкрийте його. Android першого разу попросить дозволити встановлення з браузера чи файлового менеджера — дозвольте, потім натисніть «Встановити». Більшості телефонів за останні десять років потрібен APK arm64; використовуйте armv7 лише на старих 32-бітних телефонах. Подальші оновлення можуть надходити прямо з gateway: Оновлення вкладка.

🍏

iPhone і iPad

Збірка для iOS не підписана, тому встановлюється через sideload: встановіть Набік або AltStore на комп'ютері підключіть iPhone, перетягніть .ipa і увійдіть з будь-яким Apple ID. Потім на iPhone: Налаштування → Загальні → VPN і керування пристроєм → довіртеся своєму Apple ID. З безкоштовним Apple ID додаток потрібно перевстановлювати кожні 7 днів.

🪟

Windows 10/11

Розпакуйте завантаження будь-де (наприклад C:\Programs\TrXi-Ctrl) і запустіть trxi_ctrl.exe. SmartScreen першого разу скаже "Windows захистила ваш ПК": Докладніше → Запустити все одно. Тримайте файли разом — .exe потрібні DLL і папка data поруч із ним.

🍎

macOS

Відкрийте .dmg і перетягніть TrXi-Ctrl у Програми. Першого разу клацніть програму правою кнопкою → ВІДЧИНЕНО → Відкрити (подвійний клік заблоковано, оскільки її не нотаризовано). Якщо macOS усе ще відмовляється, Системні налаштування → Конфіденційність і безпека → Відкрити все одно.

🐧

Linux

Потрібні GTK 3 і libmpv: у Debian/Ubuntu sudo apt install libgtk-3-0 libmpv2. Потім tar -xzf TrXi-Ctrl-1.1.0-linux.tar.gz і запустіть ./bundle/trxi_ctrl. Тримайте bundle теку разом.

🔗

Спаруйте зі своїм комп'ютером

На робочому столі Linux, де запущено шлюз, відкрийте http://localhost:8772/admin (або Gateway Manager). Телефони та Mac: програма → Налаштування → значок сканера QR-кодів → відскануйте QR-код або торкніться значка зображення, щоб відкрити зображення QR-коду, надіслане вам електронною поштою. Windows і Linux: введіть адресу шлюзу та код спарювання, показаний під QR-кодом. Код діє один раз і триває 10 хвилин. Обидва пристрої мають бути в одній мережі Tailscale або локальній мережі.

Встановіть шлюз

На машині з Debian Trixie (або сумісним Linux), якою ви хочете керувати

# Linux — автономний бінарний файл, більше нічого встановлювати не потрібно curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # потім у мобільному застосунку: Налаштування → URL шлюзу → http://<tailscale-або-LAN-IP-цієї-машини>:8772 # або торкніться "Discover Peers", якщо ви обидва в одній мережі Tailscale

Надаєте перевагу Python? git clone https://github.com/cou645/trixie-gateway.git, потім pip install -r requirements.txt і python3 gateway.py --port 8772. Повна документація зі встановлення, включно із запуском як служби systemd, є в репозиторії README.md.

🧪 Тестові збірки для Windows і macOS є на сторінка релізів (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). Вони не підписані, тому Windows SmartScreen скаже "невідомий видавець" (Докладніше → Виконати все одно), а macOS заблокує перший запуск (клацання правою кнопкою → Відкрити). Будь ласка, повідомте, що не працює.
