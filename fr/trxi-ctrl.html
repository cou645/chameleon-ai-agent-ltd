TrXi-Ctrl

Contrôle à distance gratuit pour votre bureau Linux — Bluetooth, pare-feu, audio, médias, fenêtres, terminal, partage d'écran, presse-papiers partagé et chat IA, le tout depuis votre téléphone — plus, sur les téléphones rootés, un point d'accès VPN et un stockage de masse USB. Conçu pour Debian Trixie ; fonctionne aussi sur la plupart des autres bureaux Linux X11.

🆓 Gratuit et ouvert 🐧 Linux / X11 uniquement 🔌 14 écrans de contrôle (+2 sur les téléphones rootés) 🤖 Serveur MCP inclus 🔒 Votre réseau, sans relais cloud

Ce qu'il fait

Une appli téléphone, un démon de passerelle sur votre bureau

🖥️

Système et couches

Statistiques en direct du CPU/de la mémoire/thermiques et bascule des couches AUFS, directement depuis le bureau.

📶

Réseau et Wi-Fi

Interfaces, adresses, analyse et connexion Wi-Fi — y compris la découverte des pairs Tailscale pour trouver votre passerelle automatiquement.

🔵

Bluetooth

Alimentation, détectable/appariable, analyse, appairage, connexion, confiance, suppression — contrôle complet de l'adaptateur.

🛡️

Pare-feu

Afficher et modifier les règles et chaînes iptables, appliquer des préréglages, depuis votre téléphone.

🔊

Audio

Volume, sourdine, liste des sorties — et diffusez la sortie audio du bureau vers le haut-parleur de votre téléphone via WebRTC.

🎬

Médias

Lecture/pause/recherche/volume réels pour Chameleon Media Center et les lecteurs basés sur MPV, via le socket IPC de mpv lui-même — pas seulement une liste de fichiers statique.

📺

CMC en direct

Regardez Chameleon Media Centerle flux en direct sur votre téléphone — choisissez Faible latence (MPEG-TS) ou Fluide (HLS) pour les connexions plus faibles — voyez s'il est en direct, sa source et combien de personnes le regardent, et copiez un lien pour que n'importe qui puisse regarder dans un navigateur.

🪟

Windows et bureaux

Lister, focaliser, fermer, réduire, agrandir, mosaïquer les fenêtres et changer de bureaux virtuels.

📲

Bureau à distance

Partage d'écran complet via WebRTC avec entrée tactile-souris et clavier — voyez et contrôlez votre bureau depuis n'importe où sur votre réseau. Entièrement fonctionnel : les appuis, glissements et frappes que vous envoyez apparaissent sur le bureau presque immédiatement. Tout décalage que vous remarquez concerne les mises à jour d'écran revenant du bureau vers votre téléphone, pas votre saisie.

📋

Presse-papiers partagé

Le PC est le hub : chaque téléphone y pousse son presse-papiers — directement dans le presse-papiers du PC, prêt à coller — et l'écran Presse-papiers liste la dernière entrée de chaque appareil. Touchez-en une pour la copier sur ce téléphone. Rien n'est lu ni écrit dans le presse-papiers de votre téléphone en arrière-plan, uniquement lorsque vous touchez.

⌨️

Terminal

Un vrai shell, exécuté depuis votre téléphone.

🤖

Chat IA

Parlez au fournisseur d'IA que vous avez configuré sur la passerelle — DeepSeek, OpenAI, Anthropic et plus encore.

Téléphones rootés

Deux écrans supplémentaires apparaissent automatiquement lorsque le téléphone est rooté (Magisk)

🔐

VPN de partage de connexion

Partagez le nœud de sortie Tailscale du téléphone avec tous les appareils de son point d'accès Wi-Fi — les ordinateurs portables, téléviseurs et consoles obtiennent le VPN sans rien installer. Le routage se réapplique automatiquement si le point d'accès ou Tailscale redémarre, et un script de démarrage peut tout restaurer après un redémarrage. Conçu pour un téléphone laissé branché en tant que routeur : une limite de charge, garder Tailscale hors de l'optimisation de la batterie et VPN toujours actif.

💾

Stockage de masse USB

Branchez le téléphone à n'importe quel PC et il apparaît comme un lecteur USB. Créez une image disque allant jusqu'à 256 Go en quelques secondes — FAT32 (tous les OS la lisent), ext4 (aucune limite de fichier de 4 Go), ou un disque GPT amorçable avec une partition EFI pour qu'un ordinateur portable puisse démarrer depuis le téléphone — puis partagez-la en lecture-écriture ou en lecture seule, ou ouvrez-la sur le téléphone lui-même. Vous pouvez aussi confier la carte SD du téléphone ou un lecteur USB au PC. ADB reste connecté pendant le partage.

La passerelle

trixie-gateway — le côté bureau, un seul binaire autonome

📦

Un seul binaire, pas besoin de Python

Téléchargez un seul exécutable autonome — pas de Python, pip ou venv sur la machine. Basé sur aiohttp + aiortc, et la source est toujours sur GitHub si vous préférez l'exécuter depuis Python. Fonctionne de manière autonome ou comme service systemd, à l'écoute sur votre adresse Tailscale/LAN.

🔌

~120 points de terminaison REST

Every phone-app feature above, plus an OpenAI-compatible /v1/chat/completions compatible OpenAI qui route vers le fournisseur d'IA que vous configurez.

🧩

Serveur MCP inclus

media_mcp_server.py expose le contrôle des médias (état, lecture, pause, avance, volume, ouverture, navigation) en tant qu'outils MCP via stdio JSON-RPC — les mêmes données de session et le même chemin de contrôle que ceux utilisés par l'application téléphone, afin qu'un agent IA et votre téléphone voient toujours la même chose.

Compatibilité

Conçu pour Debian Trixie — honnête sur les autres environnements où il fonctionne

PlateformeStatutPourquoi
Debian Trixie✓ Développé et testé ici—
Famille Fatdog64 / Puppy Linux✓ Devrait fonctionnerLa fonctionnalité Layers détecte les branches union-fs sous l'un ou l'autre /aufs (dérivé de Fatdog64, y compris cette machine) ou /initrd (Puppy standard) automatiquement — le /initrd chemin n'est pas testé contre une véritable installation de Puppy, basé sur des conventions documentées plutôt que sur une vérification pratique
Autres bureaux Linux X11✓ Devrait fonctionnerNécessite BlueZ, iptables, PulseAudio/PipeWire-avec-compatibilité-pactl et une session X11 (les bureaux uniquement Wayland ne sont pas pris en charge — wmctrl/xdotool nécessitent X11)
Windows 11🧪 Version de test expérimentaleLe partage d'écran, souris/clavier, la liste des fenêtres, le volume et le terminal sont implémentés pour Windows. Le binaire se compile et démarre dans la CI automatisée, mais n'a pas encore été exécuté sur une vraie machine Windows — attendez-vous à des aspérités. Bluetooth, pare-feu, calques, luminosité, réseau et Media Center restent réservés à Linux et répondent 501
macOS (Intel et Apple Silicon)🧪 Version de test expérimentaleLe même ensemble de fonctionnalités que Windows, utilisant Quartz, AVFoundation et osascript. Se compile et démarre dans la CI pour les deux architectures mais est non testé sur de vrais Macs. L'app n'est pas signée, et macOS demandera l'autorisation Enregistrement de l'écran et Accessibilité

Installer la passerelle

Sur la machine Debian Trixie (ou Linux compatible) que vous souhaitez contrôler

# Linux — binaire autonome, rien d'autre à installer curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # puis dans l'application mobile : Paramètres → URL de la passerelle → http://<IP Tailscale ou LAN de cette machine>:8772 # ou appuyez sur « Découvrir les pairs » si vous êtes tous les deux sur le même réseau Tailscale

Vous préférez Python ? git clone https://github.com/cou645/trixie-gateway.git, puis pip install -r requirements.txt et python3 gateway.py --port 8772. La documentation d'installation complète, y compris l'exécution en tant que service systemd, se trouve dans le dépôt README.md.

🧪 Versions de test Windows et macOS sont sur le page des versions (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). Ils ne sont pas signés, donc Windows SmartScreen affichera « éditeur inconnu » (Plus d'infos → Exécuter quand même) et macOS bloquera le premier lancement (clic droit → Ouvrir). Signalez ce qui ne fonctionne pas.
