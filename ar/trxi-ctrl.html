TrXi-Ctrl

تحكم عن بُعد مجاني لسطح مكتب Linux الخاص بك — Bluetooth، جدار الحماية، الصوت، الوسائط، النوافذ، الطرفية، مشاركة الشاشة، الحافظة المشتركة ودردشة الذكاء الاصطناعي، كل ذلك من هاتفك — بالإضافة إلى، على الهواتف المُروّتة، نقطة اتصال VPN وتخزين USB كبير السعة. مصمم لـ Debian Trixie؛ يعمل على معظم أسطح مكتب Linux الأخرى بنظام X11 أيضًا.

🆓 مجاني ومفتوح 🐧 Linux / X11 فقط 🔌 14 شاشة تحكم (+2 على الهواتف المُروّتة) 🤖 خادم MCP مضمّن 🔒 شبكتك، بدون وسيط سحابي

الطاقة، قابلية الاكتشاف/الاقتران، الفحص، الاقتران، الاتصال، الثقة، الإزالة — تحكم كامل بالمحول.

الصوت

مستوى الصوت، كتم الصوت، قائمة أحواض الصوت — وبثّ مخرج صوت سطح المكتب إلى سماعة هاتفك عبر WebRTC.

وسائط

تشغيل/إيقاف مؤقت/تقديم/مستوى صوت حقيقي لـ Chameleon Media Center والمشغلات المبنية على MPV، عبر مقبس IPC الخاص بـ mpv نفسه — وليس مجرد قائمة ملفات ثابتة.

سي ام سي لايف

شاهد Chameleon Media Centerالبث المباشر على هاتفك — اختر زمن استجابة منخفض (MPEG-TS) أو سلس (HLS) للاتصالات الأضعف — واطّلع على ما إذا كان البث مباشرًا ومصدره وعدد المشاهدين، وانسخ رابطًا ليتمكن أي شخص من المشاهدة في المتصفح.

🪟

Windows وأجهزة سطح المكتب

اعرض النوافذ وركّز عليها وأغلقها وصغّرها وكبّرها ورتّبها وبدّل أسطح المكتب الافتراضية.

📲

سطح المكتب عن بُعد

مشاركة الشاشة بالكامل عبر WebRTC مع تحويل اللمس إلى فأرة وإدخال لوحة المفاتيح — شاهد سطح مكتبك وتحكّم به من أي مكان في شبكتك. يعمل بكامل وظائفه: النقرات والسحب وضغطات المفاتيح التي ترسلها تظهر على سطح المكتب على الفور تقريبًا. أي تأخير تلاحظه يكون في تحديثات الشاشة العائدة من سطح المكتب إلى هاتفك، وليس في إدخالك.

📋

الحافظة المشتركة

الكمبيوتر هو المحور: كل هاتف يدفع حافظته إليه — مباشرة إلى حافظة الكمبيوتر نفسه، جاهزة للّصق — وتعرض شاشة الحافظة أحدث إدخال لكل جهاز. انقر على أحدها لنسخه إلى هذا الهاتف. لا يُقرأ أي شيء من حافظة هاتفك أو يُكتب فيها في الخلفية، فقط عند النقر.

⌨️

الطرفية

صدفة حقيقية، تعمل من هاتفك.

🤖

محادثة الذكاء الاصطناعي

تحدّث مع أي مزوّد ذكاء اصطناعي قمت بإعداده على البوابة — DeepSeek وOpenAI وAnthropic وغيرها.

الهواتف المُروّتة

تظهر شاشتان إضافيتان تلقائيًا عندما يكون الهاتف مُروّتًا (Magisk)

🔐

VPN نقطة الاتصال

شارك عقدة خروج Tailscale الخاصة بالهاتف مع كل جهاز على نقطة اتصال Wi-Fi الخاصة به — تحصل أجهزة الحاسوب المحمولة وأجهزة التلفاز وأجهزة الألعاب على VPN دون تثبيت أي شيء. يُعاد تطبيق التوجيه تلقائيًا إذا أُعيد تشغيل نقطة الاتصال أو Tailscale، ويمكن لسكربت الإقلاع إعادة كل شيء بعد إعادة التشغيل. مُصمَّم لهاتف يبقى موصولًا بالشاحن كموجّه: حد للشحن، وإبقاء Tailscale خارج تحسين البطارية، وVPN دائم التشغيل.

💾

وحدة تخزين USB

وصّل الهاتف بأي حاسوب وسيظهر كمحرك أقراص USB. أنشئ صورة قرص تصل إلى 256 غيغابايت في ثوانٍ — FAT32 (يقرأها كل نظام تشغيل)، أو ext4 (بلا حد ملفات 4 غيغابايت)، أو قرص GPT قابل للإقلاع مع قسم EFI ليتمكن حاسوب محمول من الإقلاع من الهاتف — ثم شاركها للقراءة والكتابة أو للقراءة فقط، أو افتحها على الهاتف نفسه. يمكنك أيضًا تسليم بطاقة SD الخاصة بالهاتف أو محرك أقراص USB إلى الحاسوب. يبقى ADB متصلًا أثناء المشاركة.

البوابة

trixie-gateway — الجانب المكتبي، ملف تنفيذي واحد مكتفٍ بذاته

📦

ملف تنفيذي واحد، بلا حاجة إلى Python

نزّل ملفًا تنفيذيًا واحدًا مكتفيًا بذاته — بلا Python أو pip أو venv على الجهاز. مبني على aiohttp + aiortc، والمصدر لا يزال على GitHub إذا كنت تفضّل تشغيله من Python. يعمل بشكل مستقل أو كخدمة systemd، ويستمع على عنوان Tailscale/LAN الخاص بك.

🔌

~120 نقطة نهاية REST

Every phone-app feature above, plus an OpenAI-compatible /v1/chat/completions متوافق مع OpenAI يوجّه إلى أي مزوّد ذكاء اصطناعي تقوم بتهيئته.

🧩

خادم MCP مضمّن

media_mcp_server.py يكشف التحكم بالوسائط (الحالة، التشغيل، الإيقاف المؤقت، التنقل، مستوى الصوت، الفتح، التصفح) كأدوات MCP عبر stdio JSON-RPC — نفس بيانات الجلسة ومسار التحكم الذي يستخدمه تطبيق الهاتف، لذا يرى وكيل الذكاء الاصطناعي وهاتفك دائمًا الشيء نفسه.

تثبيت البوابة

على جهاز Debian Trixie (أو Linux متوافق) الذي تريد التحكم به

# Linux — ملف تنفيذي مستقل، لا شيء آخر لتثبيته curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # ثم في تطبيق الهاتف: الإعدادات → عنوان URL للبوابة → http://<عنوان IP لهذا الجهاز على Tailscale أو الشبكة المحلية>:8772 # أو اضغط على "اكتشاف الأقران" إذا كنتما على نفس شبكة Tailscale

تفضل Python؟ git clone https://github.com/cou645/trixie-gateway.git، ثم pip install -r requirements.txt و python3 gateway.py --port 8772. توجد وثائق التثبيت الكاملة، بما في ذلك تشغيلها كخدمة systemd، في مستودع README.md.

🧪 إصدارات تجريبية لنظامي Windows وmacOS موجودة على صفحة الإصدارات (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). إنها غير موقّعة، لذا سيقول Windows SmartScreen "ناشر غير معروف" (مزيد من المعلومات → تشغيل على أي حال) وسيحظر macOS التشغيل الأول (انقر بزر الفأرة الأيمن → فتح). يرجى الإبلاغ عمّا لا يعمل.
