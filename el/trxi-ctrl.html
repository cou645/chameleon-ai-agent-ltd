Απομακρυσμένη επιφάνεια εργασίας

Πλήρης κοινή χρήση οθόνης μέσω WebRTC με αφή-σε-ποντίκι και εισαγωγή πληκτρολογίου — δείτε και ελέγξτε την επιφάνεια εργασίας σας από οπουδήποτε στο δίκτυό σας. Πλήρως λειτουργικό: τα πατήματα, τα συρσίματα και τα πληκτρολογήματα που στέλνετε εμφανίζονται στην επιφάνεια εργασίας σχεδόν αμέσως. VPN hotspot

Μοιραστείτε τον κόμβο εξόδου Tailscale του τηλεφώνου με κάθε συσκευή στο Wi-Fi hotspot του — φορητοί υπολογιστές, τηλεοράσεις και κονσόλες αποκτούν το VPN χωρίς να εγκαταστήσουν τίποτα. Η δρομολόγηση επανεφαρμόζεται αυτόματα αν το hotspot ή το Tailscale επανεκκινηθεί, και ένα script εκκίνησης μπορεί να τα επαναφέρει όλα μετά από επανεκκίνηση. Σχεδιασμένο για τηλέφωνο που μένει συνδεδεμένο ως router: όριο φόρτισης, διατήρηση του Tailscale εκτός βελτιστοποίησης μπαταρίας και Always-on VPN.

💾

Αποθήκευση USB

Συνδέστε το τηλέφωνο σε οποιονδήποτε υπολογιστή και εμφανίζεται ως μονάδα USB. Δημιουργήστε ένα image δίσκου έως 256 GB σε δευτερόλεπτα — FAT32 (το διαβάζει κάθε λειτουργικό σύστημα), ext4 (χωρίς όριο αρχείου 4 GB), ή έναν εκκινήσιμο δίσκο GPT με partition EFI ώστε ένας φορητός να μπορεί να εκκινήσει από το τηλέφωνο — και μετά μοιραστείτε το με δυνατότητα ανάγνωσης-εγγραφής ή μόνο ανάγνωσης, ή ανοίξτε το στο ίδιο το τηλέφωνο. Μπορείτε επίσης να δώσετε την κάρτα SD του τηλεφώνου ή μια μονάδα USB στον υπολογιστή. Το ADB παραμένει συνδεδεμένο κατά τη διάρκεια του διαμοιρασμού.

Η πύλη

trixie-gateway — η πλευρά του desktop, ένα αυτοτελές εκτελέσιμο

📦

Ένα εκτελέσιμο, χωρίς ανάγκη Python

Κατεβάστε ένα αυτοτελές εκτελέσιμο — χωρίς Python, pip ή venv στο μηχάνημα. Βασισμένο σε aiohttp + aiortc, και ο πηγαίος κώδικας είναι ακόμα στο GitHub αν προτιμάτε να το εκτελέσετε από Python. Εκτελείται αυτόνομα ή ως υπηρεσία systemd, ακούγοντας στη διεύθυνση Tailscale/LAN σας.

🔌

~120 καταληκτικά σημεία REST

Κάθε λειτουργία της εφαρμογής τηλεφώνου παραπάνω, συν ένα συμβατό με OpenAI /v1/chat/completions που δρομολογεί σε όποιον πάροχο AI διαμορφώσετε.

🧩

Περιλαμβάνεται διακομιστής MCP

media_mcp_server.py εκθέτει τον έλεγχο πολυμέσων (κατάσταση, αναπαραγωγή, παύση, αναζήτηση, ένταση, άνοιγμα, περιήγηση) ως εργαλεία MCP μέσω stdio JSON-RPC — τα ίδια δεδομένα συνεδρίας και διαδρομή ελέγχου που χρησιμοποιεί η εφαρμογή τηλεφώνου, ώστε ένας πράκτορας AI και το τηλέφωνό σας να βλέπουν πάντα το ίδιο πράγμα.

Εγκαταστήστε την πύλη

Στον υπολογιστή Debian Trixie (ή συμβατό Linux) που θέλετε να ελέγξετε

# Linux — αυτόνομο δυαδικό αρχείο, τίποτα άλλο να εγκαταστήσετε curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # στη συνέχεια στην εφαρμογή τηλεφώνου: Ρυθμίσεις → URL πύλης → http://<tailscale-ή-LAN-IP-αυτού-του-υπολογιστή>:8772 # ή πατήστε "Discover Peers" αν είστε και οι δύο στο ίδιο δίκτυο Tailscale

Προτιμάτε Python; git clone https://github.com/cou645/trixie-gateway.git, στη συνέχεια pip install -r requirements.txt και python3 gateway.py --port 8772. Πλήρης τεκμηρίωση εγκατάστασης, συμπεριλαμβανομένης της εκτέλεσης ως υπηρεσίας systemd, βρίσκεται στο αποθετήριο README.md.

🧪 Δοκιμαστικές εκδόσεις για Windows & macOS βρίσκονται στο σελίδα εκδόσεων (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). Δεν είναι υπογεγραμμένα, οπότε το Windows SmartScreen θα πει "άγνωστος εκδότης" (Περισσότερες πληροφορίες → Εκτέλεση ούτως ή άλλως) και το macOS θα αποκλείσει την πρώτη εκκίνηση (δεξί κλικ → Άνοιγμα). Παρακαλούμε αναφέρετε τι χαλάει.
