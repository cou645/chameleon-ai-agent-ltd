Cosa lo rende diverso

La maggior parte degli editor AI suggerisce. Questo opera l'editor.

🤖

L'IA apporta le modifiche

Legge il file una sola volta, poi apporta tutte le modifiche precise necessarie senza rileggerlo. Le modifiche puntano a testo esatto, non a numeri di riga, quindi non si spostano quando il file cambia. I nuovi file vengono scritti interamente, con un backup automatico di tutto ciò che sostituisce.

💻

Esegue comandi e legge i risultati

L'AI esegue comandi shell nel terminale integrato, attende ogni risultato, controlla il codice di uscita e decide cosa fare dopo. Lavoro reale in una shell live, non frammenti copiati e incollati.

🛡️

Sicuro per impostazione predefinita

Tutto ciò che l'AI legge da un file, da un terminale o da una pagina web è isolato come dati, mai come istruzioni — un file dannoso non può dirottare la sessione. Ogni modifica che apporta viene registrata con timestamp e ID di sessione, così hai una cronologia completa di ciò che è accaduto.

🔀

Rivedi prima di accettare

Un clic mostra una differenza codificata a colori delle modifiche dell'IA rispetto all'ultimo salvataggio. Accettale, continua a modificare o annulla.

🎙️

A mani libere

Dettate una domanda o un intero prompt con il riconoscimento vocale sul dispositivo e fate leggere le risposte con una voce naturale. Nulla viene inviato a un servizio di trascrizione cloud.

🔌

Porta il tuo AI

DeepSeek, OpenAI, Claude, Groq, Mistral, Kimi: cambia fornitore nel bel mezzo di un progetto. Esegui un modello localmente tramite Ollama o LM Studio senza alcun costo. Claude Code funziona come processo live direttamente nel terminale.

🧩

Modalità di lavoro impilabili

Attiva le modalità che ti servono — riparazione del codice, scrittura accademica, chat semplice — e combinale. Una stima dei costi in tempo reale viene mostrata prima di inviare qualsiasi cosa.

🗂️

Un vero editor sottostante

Modifica a più schede con undo per scheda ed evidenziazione della sintassi, albero dei file di progetto e chat in streaming che mantiene la finestra reattiva mentre i comandi vengono eseguiti in background.
