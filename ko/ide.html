카멜레온 AI IDE

AI가 작업을 대신하는 코드 에디터 — 파일을 읽고, 수정하고, 명령을 실행하고, 결과를 확인합니다. 검토하고 승인만 하면 됩니다.

🧠 AI가 코드를 직접 수정합니다 🎙️ 음성 입력, 음성 답변 🔀 수락하기 전에 변경 사항을 확인하세요 🔌 9개 AI 제공업체, 언제든지 교체 가능 🔒 로컬에서 실행되며, 키는 사용자 소유로 유지됩니다

무엇이 그것을 다르게 만드는가

대부분의 AI 편집기는 제안만 합니다. 이 제품은 편집기를 직접 작동합니다.

🤖

AI가 편집을 수행합니다

파일을 한 번 읽은 후, 다시 읽지 않고 필요한 만큼 정확한 변경을 수행합니다. 편집은 줄 번호가 아닌 정확한 텍스트를 대상으로 하므로 파일이 변경되어도 어긋나지 않습니다. 새 파일은 전체가 기록되며, 대체하는 모든 항목의 자동 백업이 생성됩니다.

💻

명령을 실행하고 결과를 읽습니다

AI는 내장 터미널에서 셸 명령을 실행하고, 각 결과를 기다린 후 종료 코드를 확인하고 다음에 무엇을 할지 결정합니다. 복사-붙여넣기 스니펫이 아닌, 실제 셸에서 실제 작업을 수행합니다.

🛡️

기본적으로 안전

AI가 파일, 터미널 또는 웹 페이지에서 읽는 모든 것은 데이터로 격리되며 명령으로 처리되지 않습니다. 악성 파일이 세션을 가로챌 수 없습니다. AI가 수행하는 모든 변경 사항은 타임스탬프와 세션 ID와 함께 기록되므로 전체 기록을 확인할 수 있습니다.

🔀

수락하기 전에 검토하세요

한 번 클릭하면 AI의 변경 사항과 마지막 저장본 간의 색상 코드 차이점이 표시됩니다. 수락하거나, 계속 편집하거나, 되돌릴 수 있습니다.

🎙️

핸즈프리

기기 내 음성-텍스트 변환으로 질문이나 전체 프롬프트를 받아쓰고, 답변을 자연스러운 음성으로 다시 들려드립니다. 클라우드 전사 서비스로 전송되는 정보는 없습니다.

🔌

나만의 AI 가져오기

DeepSeek, OpenAI, Claude, Groq, Mistral, Kimi — 프로젝트 중간에 제공자를 전환하세요. Ollama나 LM Studio를 통해 모델을 로컬에서 완전 무료로 실행하세요. Claude Code는 터미널 안에서 라이브 프로세스로 실행됩니다.

🧩

스택 가능한 작업 모드

필요한 모드를 켜세요 — 코드 수리, 학술 작성, 일반 채팅 — 그리고 조합하세요. 전송하기 전에 예상 실행 비용이 표시됩니다.

🗂️

실제 편집기가 내부에 있습니다

멀티탭 편집, 탭별 실행 취소 및 구문 강조, 프로젝트 파일 트리, 그리고 명령이 백그라운드에서 실행되는 동안 창 반응성을 유지하는 스트리밍 채팅 기능.
