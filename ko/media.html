Chameleon Media Center

mpv를 기반으로 구축된 완전한 데스크톱 미디어 스튜디오 — 재생, 재생목록, 시청하면서 캐시하는 YouTube 및 Bilibili 검색, 라이브 스트리밍, DVB-T/T2 TV, DVD/Blu-ray/CD, Bluetooth 및 USB 오디오 라우팅, 사운드 효과, 비주얼라이저, 동영상 편집기, 이퀄라이저, 가상 웹캠, 멀티폰 Android 미러링을 하나의 앱에서.

구성 내용

13개의 탭, 하나의 미디어 엔진

🎞️

비디오 패널

mpv 기반 재생 — 폭넓은 포맷 지원, 부드러운 탐색, 원클릭 전체 화면 전환(또는 F11), 플레이어 프로세스가 예기치 않게 종료되면 자동 복구, 그리고 재시작 간에 마지막으로 선택한 오디오 출력 장치를 기억해 기본값으로 재설정하지 않습니다. 저지연 PIP 오버레이는 내장 웹캠이나 모든 휴대폰 등 최대 4대의 카메라를 재생 중인 화면 모서리에 배치합니다. 재생 중인 스트림을 키 하나로 녹화하거나 재생 중인 것을 다운로드하세요.

📃

재생목록

드래그 앤 드롭 재정렬, 대기열 관리, 재생목록 가져오기 및 저장, 휴지통에서 삭제된 재생목록 복원. 단일 파일 또는 하위 폴더를 포함한 전체 폴더를 추가하세요. 파일이 없는 항목 — 연결되지 않은 USB 드라이브, 정리한 캐시된 동영상 — 은 돌아올 때까지 회색으로 표시되며, 정리한 동영상은 더블 클릭으로 다시 다운로드됩니다.

🔎

검색 및 시청 캐시

YouTube 또는 Bilibili를 검색하고, TikTok 크리에이터의 최신 동영상을 나열하거나, TikTok, Instagram, Facebook, Snapchat Spotlight 또는 Douyin 링크를 붙여넣으세요. 결과는 재생목록 아래의 번호가 매겨진 시청 목록에 대기시킵니다. 시청하는 모든 것은 시청하는 동안 디스크에 저장됩니다 — 별도 다운로드 없음 — 따라서 다음 시청은 로컬 복사본에서 재생되고, 일부 시청한 동영상은 저장된 양을 표시하고 다음에 나머지를 채웁니다. 저장된 동영상을 메인 재생목록으로 이동하고, 앱을 닫을 때 유지하거나 삭제할 항목을 선택하세요. 선택적 브라우저 쿠키로 "로봇이 아님을 확인" 및 로그인 장벽을 통과할 수 있습니다.

📡

DVB TV

실제 디지털 TV를 스캔하고 시청하세요 — DVB-T/T2, DVB-C, DVB-S/S2 및 ATSC — USB 또는 PCI 튜너에서 바로.

💿

DVD/CD/블루레이

광학 드라이브에 있는 미디어를 자동으로 감지하고 DVD-Video, Blu-ray 또는 Audio CD 트랙을 재생합니다 — 별도의 디스크 소프트웨어가 필요 없습니다.

🔵

BT/USB 오디오

재생을 한 대 또는 여러 대의 Bluetooth 스피커로 동시에 라우팅하고(PulseAudio combine-sink), 어댑터를 수신 모드로 전환해 PC 자체가 Bluetooth 스피커가 되게 하거나, 연결하세요 모든 다른 PulseAudio 캡처 소스 — USB 턴테이블, MiniDisc 데크, DJ 믹서/컨트롤러 또는 오디오 인터페이스 — 를 재생과 Visualizer에 바로 연결합니다. 모두 하나의 Input Sources 체크리스트에서.

📱

ADB 폰 — 동시에 최대 16대

원하는 만큼의 열로 배치된 1–16개의 독립 패널 그리드 — 그만큼의 Android 폰을 동시에 미러링하고 제어하며, 각각 자체 화면, 오디오 라우팅 및 입력을 가집니다. 핀치(이 박스는 터치스크린입니다) 또는 스크롤 휠로 아무 폰의 화면을 확대하고, Shift+드래그로 이동하세요. 마우스, 스타일러스, 터치 또는 실제 키보드로 직접 탭, 스와이프, 입력하세요 — 기기별로 지속되는 셸이 모든 입력을 실시간으로 유지하므로 키 입력마다 새 연결 비용을 치를 필요가 없습니다. 원클릭 "Connect Wireless"는 USB로 연결된 폰을 자동으로 adb-over-wifi로 전환하거나, 폰의 페어링 QR 코드를 스캔해 Wi-Fi로 페어링합니다. 아무 폰에나 파일을 푸시 및 풀할 수 있으며, 절전 중인 폰은 스트리밍 시작 전에 깨웁니다.

📷

가상 카메라

모든 화상 통화 앱, 브라우저 또는 OBS가 선택할 수 있는 "CMC PC Webcam" 장치 — 내장 카메라나 연결된 아무 폰의 카메라를 입력하고, 통화 중에도 앱이 장치를 잃지 않고 소스를 전환하세요. 각 폰 패널에도 자체 가상 카메라가 제공됩니다.

📡

라이브 스트림

카메라 또는 비디오 패널을 LAN 또는 Tailscale의 모든 브라우저로 스트리밍하고(HLS 플레이어 페이지), TrXi-Ctrl, VLC 또는 mpv용 저지연 피드도 제공합니다 — 한 번의 인코딩으로 여러 시청자 — 또는 YouTube Live, Facebook Live, Twitch, WeChat Channels 또는 모든 RTMP 서버로 푸시하세요.

🔗

공유 및 검색

같은 네트워크의 CMC는 서로를 자동으로 찾고, 그룹 코드로 재생목록 — 로컬 파일 포함 — 을 다른 CMC와 공유합니다.

🔔

사운드 효과

플레이하거나 스트리밍하는 동안 즉석 오디오 큐를 위한 사운드보드.

🌈

시각화 도구

현재 재생 중인 모든 것에 대한 실시간 오디오 반응형 비주얼.

✂️

비디오 편집기

프레임 단위로 정확한 클립 시퀀서: 플레이어에서 In/Out 프레임을 설정하고, 클립을 재정렬하고, 음악 트랙(원본 사운드 아래에 믹스하거나 대체)과 자막(구워 넣거나 전환 가능한 트랙으로)을 추가한 다음 백그라운드에서 내보내세요.

📲

원격 제어

모든 재생/일시정지/탐색/볼륨 동작이 mpv 자체의 IPC 소켓을 통해 노출되며, TrXi-Ctrl — 우리의 무료 휴대폰 앱 — 이 여기에 직접 연결하여 단순한 세션 목록이 아닌 실제 전송 제어를 제공합니다. 휴대폰에서 세션을 닫으면 반쯤 죽은 플레이어를 남기지 않고 앱 전체가 깔끔하게 종료됩니다.

🤖

MCP 서버

번들로 제공되는 Model Context Protocol 서버가 재생 상태, 재생/일시정지/탐색/볼륨/열기 및 라이브러리 탐색을 도구로 노출합니다 — 따라서 AI 에이전트와 휴대폰이 항상 동일한 세션을 보고 제어합니다.

개방형 기반 위에 구축

PySide6 (Qt) 데스크톱 앱, mpv 재생 엔진

🖼️

PySide6 / Qt

네이티브하고 반응성이 뛰어난 데스크톱 UI — 다른 Chameleon AI 데스크톱 앱과 동일한 Python/Qt 스택의 일부입니다.

🎬

mpv 엔진

mpv 자체의 창 임베딩과 JSON IPC 소켓을 통해 내장 — 많은 Linux 미디어 도구를 뒷받침하는 동일한 안정적이고 널리 사용되는 재생 엔진이며, 디스크 재생을 위해 libdvdnav/libdvdread/libcdio/libbluray가 이미 연결되어 있습니다.

🔊

PulseAudio 네이티브 오디오 라우팅

다중 장치 출력은 PulseAudio 자체의 module-combine-sink를 사용합니다. Bluetooth 수신 또는 USB 오디오 장치 등 모든 캡처 소스는 module-loopback을 통해 연결되며, PulseAudio 자체의 Bluetooth 정책이 이미 라우팅을 설정했는지 먼저 확인하고 충돌하지 않습니다.
