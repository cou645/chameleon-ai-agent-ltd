Chameleon Media Center

mpv를 기반으로 구축된 전체 데스크탑 미디어 스튜디오 — 재생, 재생 목록, 시청 시 캐시를 갖춘 YouTube 및 Bilibili 검색, 라이브 스트리밍, DVB-T/T2 TV, DVD/블루레이/CD, Bluetooth 및 USB 오디오 라우팅, 음향 효과, 시각화 장치, 비디오 편집기, 이퀄라이저, 가상 웹캠, 다중 전화 Android 미러링, 스케줄러, 게임 및 스포츠 점수판이 하나의 앱에 포함되어 있습니다.

🎞️ mpv 기반 재생 🔎 YouTube 및 Bilibili 검색 + 시청 캐시 📡 라이브 DVB-T/T2/C/S/ATSC TV 💿 DVD · 블루레이 · CD 🔵 Bluetooth Tx/Rx + USB 턴테이블/믹서 입력 📱 최대 16대의 휴대폰을 동시에 미러링 📷 가상 웹캠 + 4코너 PiP 📡 브라우저, YouTube, Twitch 등으로 스트리밍 🤏 각 휴대폰에서 핀치/스크롤 확대 ⏰ 예약 녹화 및 다운로드 🎮 휴대폰을 컨트롤러로 사용하는 게임 🤖 MCP 서버 포함

구성 내용

13개의 탭, 하나의 미디어 엔진

🎞️

비디오 패널

mpv로 구동되는 재생 — 폭넓은 형식 지원, 부드러운 탐색, 원클릭 전체 화면 전환(또는 F11), 플레이어 프로세스가 예기치 않게 종료되면 자동 복구, 그리고 재시작해도 기본값으로 재설정되지 않고 마지막으로 선택한 오디오 출력 장치를 기억합니다. 저지연 PIP 오버레이는 재생 중인 화면의 모서리에 최대 4대의 카메라 — 내장 웹캠 또는 모든 휴대폰 — 를 배치합니다. 재생 중인 스트림을 녹화하거나 재생 중인 것을 키 하나로 다운로드할 수 있습니다. Intel 그래픽에서는 H.264, HEVC, VP9, AV1을 GPU에서 디코딩합니다 — 더 부드러운 재생과 더 긴 배터리 수명을 위해 CPU를 약 40% 절감 — 그리고 GPU가 처리할 수 없는 것은 자동으로 소프트웨어로 폴백합니다.

📃

재생목록

드래그 앤 드롭 재정렬, 대기열 관리, 재생목록 가져오기 및 저장, 휴지통에서 삭제된 재생목록 복원. 단일 파일 또는 하위 폴더를 포함한 전체 폴더를 추가하세요. 파일이 없는 항목 — 연결되지 않은 USB 드라이브, 정리한 캐시된 동영상 — 은 돌아올 때까지 회색으로 표시되며, 정리한 동영상은 더블 클릭으로 다시 다운로드됩니다.

🔀

교체 가능한 패널

비디오를 필요한 곳에 배치하세요. 보기 → 비디오 ⇄ 재생목록(Ctrl+Shift+P)은 비디오를 오른쪽 열 상단으로, 재생목록을 왼쪽으로 이동하며, 왼쪽에서는 접을 수 있어 ADB 휴대폰이 왼쪽 열의 전체 높이를 사용할 수 있습니다. 비디오 ⇄ 시청 목록(Ctrl+Shift+W)은 대신 비디오를 재생목록 아래에 배치합니다. 교체 중에도 재생이 그대로 이어지고, 선택한 레이아웃이 기억되며, 전체 화면은 모든 레이아웃에서 작동합니다.

🔎

검색 및 시청 캐시

YouTube 또는 Bilibili를 검색하거나, TikTok 크리에이터의 최신 동영상을 나열하거나, TikTok, Instagram, Facebook, Snapchat Spotlight 또는 Douyin 링크를 붙여넣으세요. 결과는 재생목록 아래의 번호가 매겨진 시청 목록에 대기열로 추가됩니다. 시청하는 모든 것은 시청하는 동안 디스크에 저장됩니다 — 별도 다운로드 없음 — 따라서 다음 시청은 로컬 복사본에서 재생되고, 일부 시청한 동영상은 저장된 양을 표시하고 다음 번에 나머지를 채웁니다. 저장된 동영상을 메인 재생목록으로 이동하고, 앱을 닫을 때 보관하거나 삭제할 동영상을 선택하세요. 선택적 브라우저 쿠키는 "봇이 아님을 확인하세요"와 로그인 장벽을 통과합니다. 다운로드 축소를 체크하면 완료된 각 다운로드 또는 녹화가 GPU에서 최대 720p의 HEVC로 재인코딩됩니다 — 일반적으로 원본 크기의 약 3분의 1 — 결과가 더 작지 않으면 원본을 유지합니다.

📡

DVB TV

실제 디지털 TV를 스캔하고 시청하세요 — DVB-T/T2, DVB-C, DVB-S/S2 및 ATSC — USB 또는 PCI 튜너에서 바로.

💿

DVD/CD/블루레이

광학 드라이브에 있는 미디어를 자동으로 감지하고 DVD-Video, Blu-ray 또는 Audio CD 트랙을 재생합니다 — 별도의 디스크 소프트웨어가 필요 없습니다.

🔵

BT/USB 오디오

재생을 한 대 또는 여러 대의 Bluetooth 스피커로 동시에 라우팅하고(PulseAudio combine-sink), 어댑터를 수신 모드로 전환해 PC 자체가 Bluetooth 스피커가 되게 하거나, 연결하세요 모든 다른 PulseAudio 캡처 소스 — USB 턴테이블, MiniDisc 데크, DJ 믹서/컨트롤러 또는 오디오 인터페이스 — 를 재생과 Visualizer에 바로 연결합니다. 모두 하나의 Input Sources 체크리스트에서.

📱

ADB 폰 — 동시에 최대 16대

원하는 만큼의 열에 1~16개의 독립 패널로 구성된 그리드 — 그만큼의 Android 휴대폰을 동시에 미러링하고 제어하며, 각각 자체 화면, 오디오 라우팅 및 입력을 가집니다. 핀치(이 박스에는 터치스크린이 있습니다) 또는 스크롤 휠로 어떤 휴대폰의 화면이든 확대하고, Shift+드래그로 이동하세요. 마우스, 스타일러스, 터치 또는 실제 키보드로 직접 탭, 스와이프, 입력하세요 — 기기별로 지속되는 셸이 키 입력마다 새로운 연결 비용을 치르는 대신 모든 입력을 실시간으로 유지합니다. 원클릭 "무선 연결"은 USB로 연결된 휴대폰을 자동으로 adb-over-wifi로 전환하거나, 휴대폰의 페어링 QR 코드를 스캔하여 Wi-Fi로 페어링합니다. 어떤 휴대폰으로든 파일을 푸시 및 풀할 수 있으며, 절전 중인 휴대폰은 스트리밍이 시작되기 전에 깨어납니다. 미러는 낮은 지연으로 실행됩니다 — 휴대폰 화면은 사용 가능한 경우 GPU에서 디코딩 및 스케일링됩니다 — 그리고 각 패널에는 휴대폰의 PC 오디오를 정확히 적절한 밀리초만큼 지연시키는 A/V 동기화 컨트롤이 있어 소리와 화면이 일치합니다. "화면 끄기"는 PC에서 계속 보고 제어하는 동안 휴대폰 자체 디스플레이를 꺼두고, 앱을 닫으면 모든 휴대폰의 오디오와 화면이 깔끔하게 정상으로 돌아옵니다.

📷

가상 카메라

모든 화상 통화 앱, 브라우저 또는 OBS가 선택할 수 있는 "CMC PC Webcam" 장치 — 내장 카메라나 연결된 아무 폰의 카메라를 입력하고, 통화 중에도 앱이 장치를 잃지 않고 소스를 전환하세요. 각 폰 패널에도 자체 가상 카메라가 제공됩니다.

📡

라이브 스트림

카메라 또는 비디오 패널을 LAN 또는 Tailscale의 모든 브라우저로 스트리밍(HLS 플레이어 페이지)하고 TrXi-Ctrl, VLC 또는 mpv용 저지연 피드도 제공 — 한 번의 인코딩으로 많은 시청자 — 또는 YouTube Live, Facebook Live, Twitch, WeChat Channels 또는 모든 RTMP 서버로 푸시하세요. Intel 그래픽에서는 스트림이 CPU 대신 GPU에서 인코딩됩니다.

🔗

공유 및 검색

같은 네트워크의 CMC는 서로를 자동으로 찾고, 그룹 코드로 재생목록 — 로컬 파일 포함 — 을 다른 CMC와 공유합니다.

🔔

사운드 효과

축구 킥, 골 응원, 게임에서 사용되는 관중 소리 등 게임을 플레이하거나 스트리밍하는 동안 즉각적인 오디오 신호를 제공하는 사운드보드입니다.

🌈

시각화 도구

현재 재생 중인 모든 것에 대한 실시간 오디오 반응형 비주얼.

✂️

비디오 편집기

프레임 단위의 정확한 비디오 편집기: 프레임 번호 또는 재생 프레임에서 시작 및 종료를 설정한 다음 잘라냅니다(섹션을 유지하거나 제거하고 나머지를 결합). 비디오, 이미지, 메모 및 사운드의 타이틀 카드를 추가하고 크로스페이드, 흑백으로 전환, 디졸브, 와이프, 슬라이드, 아이리스, 확대/축소, 흐림 등 14가지 전환 기능을 사용하여 순서대로 드래그하세요. 세 가지 오디오 트랙(클립 고유의 사운드, 음악, 사운드 효과)을 각각 고유한 볼륨과 미리보기에서 직접 구성한 볼륨 그래프로 믹싱합니다. 자막이 번인되거나 전환 가능합니다. 실행 취소 및 다시 실행; 내보내기는 가능한 경우 GPU 하드웨어 인코더의 백그라운드에서 실행됩니다.

⏰

일정

특정 시간 및 요일 또는 한 번에 대한 작업 설정: 파일 또는 스트림 재생, 중지, 몇 분 동안 스트림 또는 DVB 채널 녹화, YouTube 검색의 상위 결과 가져오기, 채널 또는 재생 목록에서 새 비디오만 다운로드, 무언가가 움직일 때만 웹캠 녹화(각 이벤트 전후 몇 초) 또는 명령 실행. CMC가 열려 있는 동안 작업이 실행되고, CMC가 닫혀 있는 작업 시간에 CMC가 자동으로 시작될 수 있습니다. 각 작업은 다른 국가에서만 사용할 수 있는 소스의 경우 Tailscale 종료 노드를 통과할 수 있습니다.

🧩

플러그인

X11에서 또는 mpvpaper를 사용하여 Wayland에서 바탕화면 배경화면으로 비디오(현재 비디오 또는 모든 파일)를 재생하십시오. 플러그인 탭에는 한 비디오의 여러 A-B 루프 섹션과 같은 다른 작성자의 선택적인 추가 항목도 해당 라이센스, 다운로드 링크 및 설치 여부와 함께 나열됩니다. 타사 제품은 번들로 제공되지 않습니다.

🎮

계략

체스, 백개먼, 바둑, 클론다이크 솔리테어, 마작 솔리테어, 전함, 틱택토, 사각형(점과 상자), 주사위, 바운티 하이스트 풋볼 등 미디어가 계속 진행되는 동안 보드, 카드, 테이블 게임을 즐길 수 있는 게임 탭입니다. 선택한 레벨(체스의 경우 Stockfish, Go의 경우 GNU Go)로 컴퓨터를 플레이하거나 한 화면에서 두 사람 또는 네트워크를 통해 친구와 플레이할 수 있습니다. 모든 게임은 점수를 유지합니다. 턴제 게임은 원격 데스크톱을 통해 어디서나 플레이할 수 있습니다. TrXi-Ctrl. 실시간 게임의 경우 휴대폰은 컨트롤러가 됩니다. TrXi-Ctrl을 실행하는 휴대폰은 Wi-Fi 또는 USB 케이블을 통해 연결되며 각각에는 조이스틱, 버튼, 킥오프 및 일시 정지, 라이브 점수 및 진동이 포함됩니다.

⚽

현상금 강도 축구

독창적인 축구 게임: 크루들은 Vault에서 현상금을 훔치기 위해 경쟁하고, 모든 목표에 대해 포인트를 획득하며, 가장 많은 전리품을 가진 크루가 승리합니다. 2~4명의 팀이 컴퓨터를 상대로, 친구들과 함께 컨트롤러로 전화를 하거나, 네트워크를 통해 발차기 소리, 골 환호 소리, 관중이 함께(또는 조용히 플레이) 합니다. 원격 제어

모든 재생/일시정지/탐색/볼륨 동작이 mpv 자체의 IPC 소켓을 통해 노출되며, TrXi-Ctrl — 우리의 무료 휴대폰 앱 — 이 여기에 직접 연결하여 단순한 세션 목록이 아닌 실제 전송 제어를 제공합니다. 휴대폰에서 세션을 닫으면 반쯤 죽은 플레이어를 남기지 않고 앱 전체가 깔끔하게 종료됩니다.

🤖

MCP 서버

번들로 제공되는 Model Context Protocol 서버가 재생 상태, 재생/일시정지/탐색/볼륨/열기 및 라이브러리 탐색을 도구로 노출합니다 — 따라서 AI 에이전트와 휴대폰이 항상 동일한 세션을 보고 제어합니다.

개방형 기반 위에 구축

PySide6 (Qt) 데스크톱 앱, mpv 재생 엔진

🖼️

PySide6 / Qt

네이티브하고 반응성이 뛰어난 데스크톱 UI — 다른 Chameleon AI 데스크톱 앱과 동일한 Python/Qt 스택의 일부입니다.

🎬

mpv 엔진

mpv 자체의 창 임베딩과 JSON IPC 소켓을 통해 내장 — 많은 Linux 미디어 도구를 뒷받침하는 동일한 안정적이고 널리 사용되는 재생 엔진이며, 디스크 재생을 위해 libdvdnav/libdvdread/libcdio/libbluray가 이미 연결되어 있습니다.

🔊

PulseAudio 네이티브 오디오 라우팅

다중 장치 출력은 PulseAudio 자체의 module-combine-sink를 사용합니다. Bluetooth 수신 또는 USB 오디오 장치 등 모든 캡처 소스는 module-loopback을 통해 연결되며, PulseAudio 자체의 Bluetooth 정책이 이미 라우팅을 설정했는지 먼저 확인하고 충돌하지 않습니다.
