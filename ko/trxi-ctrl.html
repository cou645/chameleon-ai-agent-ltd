TrXi-Ctrl

Linux 데스크톱을 위한 무료 원격 제어 — Bluetooth, 방화벽, 오디오, 미디어, 창, 터미널, 화면 공유, 공유 클립보드 및 AI 채팅을 휴대폰이나 다른 컴퓨터에서 — 또한 루팅된 휴대폰에서는 VPN 핫스팟과 USB 대용량 저장소. Debian Trixie용으로 제작되었으며, 대부분의 다른 X11 Linux 데스크톱에서도 작동합니다.

원격 데스크톱

WebRTC를 통한 전체 화면 공유, PC 사운드 포함 — 네트워크 어디서든 데스크톱을 보고 제어할 수 있습니다. 휴대폰에서는 터치로 마우스를 조작하고 화면 막대로 텍스트를 보냅니다. Windows, macOS, Linux 앱에서는 자신의 마우스와 키보드가 직접 작동합니다. 클릭과 키 입력은 거의 즉시 데스크톱에 나타납니다. 느껴지는 지연은 돌아오는 화면 업데이트에 있는 것이지 입력에 있는 것이 아닙니다.

공유 클립보드

PC가 허브입니다: 모든 휴대폰이 클립보드를 그곳으로 보냅니다 — PC 자체의 클립보드에 바로, 붙여넣을 준비가 된 상태로 — 그리고 클립보드 화면에는 각 기기의 최신 항목이 나열됩니다. 하나를 탭하면 이 휴대폰으로 복사됩니다. 백그라운드에서 휴대폰의 클립보드를 읽거나 쓰지 않으며, 탭할 때만 합니다.

핫스팟 VPN

휴대폰의 Tailscale 출구 노드를 Wi-Fi 핫스팟의 모든 기기와 공유하세요 — 노트북, TV, 콘솔이 아무것도 설치하지 않고 VPN을 사용할 수 있습니다. 핫스팟이나 Tailscale이 재시작되면 라우팅이 자동으로 다시 적용되며, 부팅 스크립트로 재부팅 후 모든 것을 복원할 수 있습니다. 라우터로 계속 꽂아 두는 휴대폰을 위해 설계되었습니다: 충전 제한, Tailscale을 배터리 최적화에서 제외, 항상 켜진 VPN.

💾

USB 대용량 저장소

휴대폰을 아무 PC에나 연결하면 USB 드라이브로 나타납니다. 최대 256GB의 디스크 이미지를 몇 초 만에 생성하세요 — FAT32(모든 OS에서 읽음), ext4(4GB 파일 제한 없음), 또는 EFI 파티션이 있는 부팅 가능한 GPT 디스크로 노트북이 휴대폰에서 부팅 가능 — 그런 다음 읽기-쓰기 또는 읽기 전용으로 공유하거나 휴대폰 자체에서 열 수 있습니다. 휴대폰의 SD 카드나 USB 드라이브를 PC에 넘겨줄 수도 있습니다. 공유하는 동안 ADB는 계속 연결된 상태로 유지됩니다.

앱 설치

아직 Apple이나 Microsoft에서 서명한 빌드가 없으므로, 각 시스템은 신뢰할지 한 번씩 묻습니다

🤖

기계적 인조 인간

휴대폰에서 APK를 다운로드하고 엽니다. Android는 처음에 브라우저나 파일 관리자에서 설치를 허용할지 묻습니다 — 허용한 다음 설치를 누르세요. 지난 10년간의 대부분의 휴대폰은 arm64 APK를 필요로 합니다. armv7은 오래된 32비트 휴대폰에서만 사용하세요. 이후 업데이트는 게이트웨이에서 바로 받을 수 있습니다: 업데이트 탭.

🍏

iPhone 및 iPad

iOS 빌드는 서명되지 않았으므로 사이드로드합니다: 설치 사이드로드 방식 또는 알트스토어 를 컴퓨터에서, iPhone을 연결하고, .ipa 을 드롭한 후 아무 Apple ID로 로그인하세요. 그런 다음 iPhone에서: 설정 → 일반 → VPN 및 기기 관리 → Apple ID를 신뢰하세요. 무료 Apple ID의 경우 앱을 7일마다 다시 사이드로드해야 합니다.

🪟

윈도우 10/11

다운로드한 파일을 아무 곳에나 압축 해제하고 (예: C:\Programs\TrXi-Ctrl) 실행하세요 trxi_ctrl.exe. 처음에는 SmartScreen이 "Windows에서 PC를 보호했습니다"라고 표시합니다: 추가 정보 → 실행. 파일을 함께 보관하세요 — .exe에는 DLL과 data 폴더가 옆에 필요합니다.

🍎

macOS

열고 .dmg 끌어다 놓습니다 TrXi-Ctrl 으로 응용. 처음에는 앱을 마우스 오른쪽 버튼으로 클릭 → 열려 있는 → 열기 (공증되지 않았기 때문에 더블 클릭이 차단됩니다). macOS가 계속 거부하면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기.

리눅스

GTK 3 및 libmpv 필요: Debian/Ubuntu에서 sudo apt install libgtk-3-0 libmpv2. 그런 다음 tar -xzf TrXi-Ctrl-1.1.0-linux.tar.gz 를 실행합니다 ./bundle/trxi_ctrl. 폴더를 bundle 함께 유지하세요.

데스크톱과 페어링

게이트웨이를 실행하는 Linux 데스크톱에서 열기 http://localhost:8772/admin (또는 Gateway Manager). 휴대폰 및 Mac: 앱 → 설정 → QR 스캐너 아이콘 → QR을 스캔하거나, 이미지 아이콘을 탭하여 누군가 이메일로 보낸 QR 이미지를 엽니다. Windows 및 Linux: 게이트웨이 주소와 QR 아래에 표시된 페어링 코드를 입력하세요. 코드는 한 번만 작동하며 10분 동안 유효합니다. 두 기기 모두 동일한 Tailscale 네트워크 또는 LAN에 있어야 합니다.

게이트웨이 설치

제어하려는 Debian Trixie(또는 호환 Linux) 머신에서

# Linux — 독립 실행형 바이너리, 그 외 설치할 것 없음 curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # 그런 다음 휴대폰 앱에서: 설정 → 게이트웨이 URL → http://<이 머신의 Tailscale 또는 LAN IP>:8772 # 또는 둘 다 같은 Tailscale 네트워크에 있다면 "피어 검색"을 탭하세요

Python을 선호하시나요? git clone https://github.com/cou645/trixie-gateway.git, 그런 다음 pip install -r requirements.txt 그리고 python3 gateway.py --port 8772. systemd 서비스로 실행하는 것을 포함한 전체 설치 문서는 저장소의 README.md.

🧪 Windows 및 macOS 테스트 빌드 는 여기에 있습니다 릴리스 페이지 (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). 서명되지 않았으므로 Windows SmartScreen은 "알 수 없는 게시자"라고 표시하고(추가 정보 → 실행) macOS는 첫 실행을 차단합니다(마우스 오른쪽 버튼 클릭 → 열기). 문제가 있으면 알려주세요.
