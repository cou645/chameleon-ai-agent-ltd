TrXi-Ctrl

Free remote control for your Linux desktop — Bluetooth, firewall, audio, media, windows, terminal, screen share and AI chat, all from your phone. Built for Debian Trixie; works on most other X11 Linux desktops too.

🆓 Free & open 🐧 Linux / X11 only 🔌 12 control screens 🤖 MCP server included 🔒 Your network, no cloud relay

What it does

One phone app, one gateway daemon on your desktop

🖥️

System & layers

Live CPU/memory/thermal stats and AUFS layer toggling, straight from the desktop.

📶

Network & Wi-Fi

Interfaces, addresses, Wi-Fi scan and connect — including Tailscale peer discovery to find your gateway automatically.

🔵

Bluetooth

Power, discoverable/pairable, scan, pair, connect, trust, remove — full adapter control.

🛡️

Firewall

View and edit iptables rules and chains, apply presets, from your phone.

🔊

Audio

Volume, mute, sink list — and stream the desktop's audio output to your phone's speaker over WebRTC.

🎬

Media

Real play/pause/seek/volume for Chameleon Media Center and MPV-based players, via mpv's own IPC socket — not just a static file listing.

🪟

Windows & desktops

List, focus, close, minimize, maximize, tile windows and switch virtual desktops.

📲

Remote desktop

Full screen share over WebRTC with touch-to-mouse and keyboard input — see and control your desktop from anywhere on your network.

⌨️

Terminal

A real shell, run from your phone.

🤖

AI chat

Talk to whichever AI provider you've configured on the gateway — DeepSeek, OpenAI, Anthropic and more.

The gateway

trixie-gateway — the desktop side, a single self-contained binary

📦

One binary, no Python needed

Download a single self-contained executable — no Python, pip or venv on the machine. Built on aiohttp + aiortc, and the source is still on GitHub if you'd rather run it from Python. Runs standalone or as a systemd service, listening on your Tailscale/LAN address.

🔌

~120 REST endpoints

Every phone-app feature above, plus an OpenAI-compatible /v1/chat/completions that routes to whichever AI provider you configure.

🧩

MCP server included

media_mcp_server.py exposes media control (status, play, pause, seek, volume, open, browse) as MCP tools over stdio JSON-RPC — the same session data and control path the phone app uses, so an AI agent and your phone always see the same thing.

Compatibility

Built for Debian Trixie — honest about where else it runs

PlatformStatusWhy
Debian Trixie✓ Developed & tested here—
Fatdog64 / Puppy Linux family✓ Should workThe Layers feature detects union-fs branches under either /aufs (Fatdog64-derived, incl. this box) or /initrd (standard Puppy) automatically — the /initrd path is untested against a real Puppy install, based on documented conventions rather than hands-on verification
Other X11 Linux desktops✓ Should workNeeds BlueZ, iptables, PulseAudio/PipeWire-with-pactl-compat, and an X11 session (Wayland-only desktops aren't supported — wmctrl/xdotool need X11)
Windows 11🧪 Experimental test buildScreen share, mouse/keyboard, window list, volume and terminal are implemented for Windows. The binary builds and starts in automated CI, but has not yet been run on a real Windows machine — expect rough edges. Bluetooth, firewall, layers, brightness, network and Media Center remain Linux-only and answer 501
macOS (Intel & Apple Silicon)🧪 Experimental test buildSame feature set as Windows, using Quartz, AVFoundation and osascript. Builds and starts in CI for both architectures but is untested on real Macs. The app is unsigned, and macOS will ask for Screen Recording and Accessibility permission

Install the gateway

On the Debian Trixie (or compatible Linux) machine you want to control

# Linux — standalone binary, nothing else to install curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # then in the phone app: Settings → Gateway URL → http://<this-machine's-tailscale-or-LAN-ip>:8772 # or tap "Discover Peers" if you're both on the same Tailscale network

Prefer Python? git clone https://github.com/cou645/trixie-gateway.git, then pip install -r requirements.txt and python3 gateway.py --port 8772. Full install docs, including running it as a systemd service, are in the repo's README.md.

🧪 Windows & macOS test builds are on the releases page (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). They are unsigned, so Windows SmartScreen will say "unknown publisher" (More info → Run anyway) and macOS will block the first launch (right-click → Open). Please report what breaks.
