TrXi-Ctrl

Free remote control for your Linux desktop — Bluetooth, firewall, audio, media, windows, terminal, screen share, shared clipboard and AI chat, from your phone or from another computer — plus, on rooted phones, a VPN hotspot and USB mass storage. Built for Debian Trixie; works on most other X11 Linux desktops too.

🆓 Free for personal use 🆕 Version 1.2.0 📱 Android & iOS · 💻 Windows, macOS & Linux apps 🐧 Controls Linux / X11 desktops 🔌 17 screens (+2 on rooted phones) 🤖 MCP server included 🔒 Your own network, no account needed

What's new

1.2.0 and gateway 0.3.1, October 2026

🔐

Encrypted on your home network too

Over Tailscale the connection was already encrypted. On a home network the app now uses HTTPS and checks the gateway's own certificate fingerprint, which arrives with the pairing QR.

🛡️

Security review fixes

Gateway 0.3.1 closes the gaps found in our ISO 27001 review: revocable devices, Tailscale-only by default, terminal access granted per device, a tamper-evident log, and a root helper so the gateway can run as a normal user.

⚠️

Safety prompts

A risk notice on first launch, and commands that delete, overwrite, encrypt, format or shut down ask before they run.

💻

Desktop apps

TrXi-Ctrl now runs on Windows, macOS and Linux as well as phones. Control your Linux machine from a laptop: the same screens, with a real mouse and keyboard.

🖱️

Mouse & keyboard remote desktop

Move, click (left, middle, right), drag and scroll the remote screen with your mouse; type and use shortcuts like Ctrl+C on your own keyboard. Touch controls on phones are unchanged.

🔇

Sound with the picture

Remote desktop plays the PC's sound along with the screen, with a mute button on the Desktop tab.

🖼️

Pair from a picture or a code

Not next to the PC? Someone there can email you the pairing QR — open the picture in the app's scanner (image icon). Computers without a camera type the pairing code instead.

🛡️

Devices & whitelist

The gateway's admin page lists every device that has connected and whether it's online, and can let in only the devices you tick — by Tailscale name or, on your home network, MAC address.

🎛️

Gateway Manager

A small desktop panel to start, stop and restart the gateway service, show, save or copy the pairing QR, and read the gateway's log.

Windows & desktops

List, focus, close, minimize, maximize, tile windows and switch virtual desktops.

📲

Remote desktop

Full screen share over WebRTC, with the PC's sound — see and control your desktop from anywhere on your network. On a phone, touch drives the mouse and an on-screen bar sends text; in the Windows, macOS and Linux apps your own mouse and keyboard work directly. Clicks and keystrokes show up on the desktop almost immediately; any lag you notice is in the screen updates coming back, not in your input.

📋

Shared clipboard

The PC is the hub: every device pushes its clipboard there — straight into the PC's own clipboard, ready to paste — and the Clipboard screen shows a shared history of the last 50 items. Send an item to chosen devices or groups, mute devices you don't want to hear from, and tap an item to copy it to this device. Nothing is read from or written to your phone's clipboard in the background, only when you tap.

⌨️

Terminal

A real shell, run from your phone.

🤖

AI chat

Talk to whichever AI provider you've configured on the gateway — DeepSeek, OpenAI, Anthropic and more.

Rooted phones

Two extra screens appear automatically when the phone has root (Magisk)

🔐

Hotspot VPN

Share the phone's Tailscale exit node with every device on its Wi-Fi hotspot — laptops, TVs and consoles get the VPN without installing anything. Routing re-applies itself if the hotspot or Tailscale restarts, and a boot script can bring it all back after a reboot. Built for a phone left plugged in as a router: a charge limit, keep Tailscale out of battery optimisation, and Always-on VPN.

💾

USB mass storage

Plug the phone into any PC and it appears as a USB drive. Create a disk image of up to 256 GB in seconds — FAT32 (every OS reads it), ext4 (no 4 GB file limit), or a bootable GPT disk with an EFI partition so a laptop can boot from the phone — then share it read-write or read-only, or open it on the phone itself. You can also hand the phone's SD card or a USB drive to the PC. ADB stays connected while sharing.

The gateway

trixie-gateway — the desktop side, a single self-contained binary

📦

One binary, no Python needed

Download a single self-contained executable — no Python, pip or venv on the machine. Since v0.3.0 it answers only over Tailscale (or HTTPS on your home network, if you turn that on) and from the PC itself, new devices start without terminal access, and lost devices can be revoked from the admin page. Built on aiohttp + aiortc, and the source is still on GitHub if you'd rather run it from Python. Runs standalone or as a systemd service, listening on your Tailscale/LAN address.

🔌

~110 REST endpoints

Every phone-app feature above, plus an OpenAI-compatible /v1/chat/completions that routes to whichever AI provider you configure.

🧩

MCP server included

media_mcp_server.py exposes media control (status, play, pause, seek, volume, open, browse) as MCP tools over stdio JSON-RPC — the same session data and control path the phone app uses, so an AI agent and your phone always see the same thing.

Install the app

None of the builds are signed by Apple or Microsoft yet, so each system asks once whether you trust it

🤖

Android

Download the APK on the phone and open it. Android asks to allow installs from your browser or file manager the first time — allow it, then Install. Most phones from the last ten years want the arm64 APK; use armv7 only on old 32-bit phones. Later updates can come straight from the gateway: Updates tab.

🍏

iPhone & iPad

The iOS build is unsigned, so it's sideloaded: install Sideloadly or AltStore on a computer, connect the iPhone, drop in the .ipa and sign in with any Apple ID. Then on the iPhone: Settings → General → VPN & Device Management → trust your Apple ID. With a free Apple ID the app must be re-sideloaded every 7 days.

🪟

Windows 10 / 11

Unzip the download anywhere (for example C:\Programs\TrXi-Ctrl) and run trxi_ctrl.exe. SmartScreen says "Windows protected your PC" the first time: More info → Run anyway. Keep the files together — the .exe needs the DLLs and data folder next to it.

🍎

macOS

Open the .dmg and drag TrXi-Ctrl into Applications. The first time, right-click the app → Open → Open (a double-click is blocked because it isn't notarised). If macOS still refuses, System Settings → Privacy & Security → Open Anyway.

🐧

Linux

Needs GTK 3 and libmpv: on Debian/Ubuntu sudo apt install libgtk-3-0 libmpv2. Then tar -xzf TrXi-Ctrl-1.2.0-linux.tar.gz and run ./bundle/trxi_ctrl. Keep the bundle folder together.

🔗

Pair with your desktop

On the Linux desktop running the gateway, open http://localhost:8772/admin (or the Gateway Manager). Phones and Macs: app → Settings → QR-scanner icon → scan the QR, or tap the image icon to open a QR picture someone emailed you. Windows and Linux: enter the gateway address and the pairing code shown under the QR. A code works once and lasts 10 minutes. Both devices need to be on the same Tailscale network (home-network access is off unless you turn it on). New devices can't use the Terminal until you tick Terminal for them on the admin page.

Install the gateway

On the Debian Trixie (or compatible Linux) machine you want to control

# Linux — standalone binary, nothing else to install curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.3.1/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # then in the app: Settings → Gateway URL → http://<this-machine's-tailscale-ip>:8772 # or tap "Discover Peers" if you're both on the same Tailscale network

Prefer Python? git clone https://github.com/cou645/trixie-gateway.git, then pip install -r requirements.txt and python3 gateway.py --port 8772. Full install docs, including running it as your own user (recommended) or as a system service, are in the repo's README.md.

🔏 Check your download. Every release has a SHA256SUMS.txt signed with our release key, trxi-release.pub. With the three files next to your download: openssl pkeyutl -verify -pubin -inkey trxi-release.pub -rawin -in SHA256SUMS.txt -sigfile SHA256SUMS.txt.sig must say "Signature Verified Successfully", then sha256sum -c --ignore-missing SHA256SUMS.txt must say OK.

🧪 Windows & macOS test builds are on the releases page (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). They are unsigned, so Windows SmartScreen will say "unknown publisher" (More info → Run anyway) and macOS will block the first launch (right-click → Open). Please report what breaks.
