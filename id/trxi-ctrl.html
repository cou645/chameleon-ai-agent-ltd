TrXi-Ctrl

Kontrol jarak jauh gratis untuk desktop Linux Anda — Bluetooth, firewall, audio, media, jendela, terminal, berbagi layar, papan klip bersama, dan obrolan AI, dari ponsel Anda atau dari komputer lain — plus, pada ponsel yang sudah di-root, hotspot VPN dan penyimpanan massal USB. Dibuat untuk Debian Trixie; juga berfungsi di sebagian besar desktop Linux X11 lainnya.

🆓 Gratis untuk penggunaan pribadi 🆕 Versi 1.1.0 📱 Android & iOS · 💻 Aplikasi Windows, macOS & Linux 🐧 Kontrol desktop Linux / X11 🔌 17 layar (+2 di ponsel yang di-root) 🤖 Server MCP disertakan 🔒 Jaringan Anda sendiri, tanpa perlu akun

Apa yang baru di 1.1.0

Oktober 2026

💻

Aplikasi desktop

TrXi-Ctrl kini berjalan di Windows, macOS, dan Linux serta ponsel. Kendalikan mesin Linux Anda dari laptop: layar yang sama, dengan mouse dan keyboard sungguhan.

🖱️

Desktop jarak jauh dengan mouse & keyboard

Pindahkan, klik (kiri, tengah, kanan), seret, dan gulir layar jarak jauh dengan mouse Anda; ketik dan gunakan pintasan seperti Ctrl+C di keyboard Anda sendiri. Kontrol sentuh di ponsel tidak berubah.

🔇

Suara bersama gambar

Desktop jarak jauh memutar suara PC bersama layar, dengan tombol bisu di tab Desktop.

🖼️

Pasangkan dari gambar atau kode

Tidak di dekat PC? Seseorang di sana dapat mengirimkan QR pemasangan melalui email — buka gambar di pemindai aplikasi (ikon gambar). Komputer tanpa kamera mengetikkan kode pemasangan sebagai gantinya.

🛡️

Perangkat & daftar putih

Halaman admin gateway mencantumkan setiap perangkat yang pernah terhubung dan apakah online, dan dapat mengizinkan hanya perangkat yang Anda centang — berdasarkan nama Tailscale atau, di jaringan rumah Anda, alamat MAC.

🎛️

Pengelola Gateway

Panel desktop kecil untuk memulai, menghentikan, dan memulai ulang layanan gateway, menampilkan, menyimpan, atau menyalin QR pemasangan, dan membaca log gateway.

Apa yang dilakukannya

Satu aplikasi ponsel, satu daemon gateway di desktop Anda

🖥️

Sistem & lapisan

Statistik CPU/memori/termal langsung dan pengalihan lapisan AUFS, langsung dari desktop.

📶

Jaringan & Wi-Fi

Antarmuka, alamat, pemindaian dan koneksi Wi-Fi — termasuk penemuan peer Tailscale untuk menemukan gateway Anda secara otomatis.

🔵

Bluetooth

Daya, dapat ditemukan/dipasangkan, pindai, pasangkan, sambungkan, percayai, hapus — kontrol adaptor penuh.

🛡️

tembok api

Lihat dan edit aturan dan rantai iptables, terapkan preset, dari ponsel Anda.

🔊

Audio

Volume, mute, daftar sink — dan streaming output audio desktop ke speaker ponsel Anda melalui WebRTC.

🎬

Media

Play/pause/seek/volume sungguhan untuk Chameleon Media Center dan pemutar berbasis MPV, melalui soket IPC milik mpv sendiri — bukan sekadar daftar file statis.

📺

CMC Langsung

Tonton Chameleon Media Centersiaran langsung di ponsel Anda — pilih Low latency (MPEG-TS) atau Smooth (HLS) untuk koneksi lemah — lihat apakah sedang live, sumbernya dan berapa banyak yang menonton, dan salin tautan agar siapa pun dapat menonton di browser.

🪟

Windows & desktop

Daftar, fokus, tutup, perkecil, perbesar, susun jendela dan ganti desktop virtual.

📲

Desktop jarak jauh

Berbagi layar penuh melalui WebRTC, dengan suara PC — lihat dan kendalikan desktop Anda dari mana saja di jaringan Anda. Di ponsel, sentuhan menggerakkan mouse dan bilah di layar mengirim teks; di aplikasi Windows, macOS, dan Linux, mouse dan keyboard Anda sendiri bekerja secara langsung. Klik dan penekanan tombol muncul di desktop hampir seketika; jeda apa pun yang Anda perhatikan ada pada pembaruan layar yang kembali, bukan pada input Anda.

📋

Papan klip bersama

PC adalah pusatnya: setiap perangkat mendorong papan klipnya ke sana — langsung ke papan klip PC sendiri, siap ditempel — dan layar Papan Klip menampilkan riwayat bersama dari 50 item terakhir. Kirim item ke perangkat atau grup tertentu, bisukan perangkat yang tidak ingin Anda dengar, dan ketuk item untuk menyalinnya ke perangkat ini. Tidak ada yang dibaca dari atau ditulis ke papan klip ponsel Anda di latar belakang, hanya saat Anda mengetuk.

⌨️

Terminal

Shell sungguhan, dijalankan dari ponsel Anda.

🤖

Obrolan AI

Bicaralah dengan penyedia AI mana pun yang telah Anda konfigurasi di gateway — DeepSeek, OpenAI, Anthropic dan lainnya.

Ponsel yang di-root

Dua layar tambahan muncul otomatis saat ponsel memiliki root (Magisk)

🔐

VPN hotspot

Bagikan node keluar Tailscale ponsel ke setiap perangkat di hotspot Wi-Fi-nya — laptop, TV, dan konsol mendapatkan VPN tanpa menginstal apa pun. Perutean diterapkan ulang secara otomatis jika hotspot atau Tailscale restart, dan skrip boot dapat memulihkan semuanya setelah reboot. Dibuat untuk ponsel yang dibiarkan terpasang sebagai router: batas pengisian daya, jaga Tailscale dari optimasi baterai, dan Always-on VPN.

💾

Penyimpanan massal USB

Colokkan ponsel ke PC mana pun dan ponsel muncul sebagai drive USB. Buat image disk hingga 256 GB dalam hitungan detik — FAT32 (dibaca semua OS), ext4 (tanpa batas file 4 GB), atau disk GPT yang dapat di-boot dengan partisi EFI sehingga laptop dapat boot dari ponsel — lalu bagikan sebagai baca-tulis atau hanya-baca, atau buka di ponsel itu sendiri. Anda juga dapat menyerahkan kartu SD ponsel atau drive USB ke PC. ADB tetap terhubung selama berbagi.

Gerbang

trixie-gateway — sisi desktop, satu biner mandiri

📦

Satu biner, tanpa perlu Python

Unduh satu eksekutabel mandiri — tanpa Python, pip, atau venv di mesin. Biner saat ini (v0.2.0-test2, September 2026) mendahului perbaikan keamanan Oktober; sampai versi baru diterbitkan, jalankan gateway dari sumber untuk mendapatkannya. Dibangun di atas aiohttp + aiortc, dan sumbernya masih ada di GitHub jika Anda lebih suka menjalankannya dari Python. Berjalan mandiri atau sebagai layanan systemd, mendengarkan di alamat Tailscale/LAN Anda.

🔌

~110 endpoint REST

Setiap fitur aplikasi ponsel di atas, plus yang kompatibel dengan OpenAI /v1/chat/completions yang merutekan ke penyedia AI mana pun yang Anda konfigurasikan.

🧩

Server MCP disertakan

media_mcp_server.py mengekspos kontrol media (status, putar, jeda, cari, volume, buka, jelajah) sebagai alat MCP melalui stdio JSON-RPC — data sesi dan jalur kontrol yang sama dengan yang digunakan aplikasi ponsel, sehingga agen AI dan ponsel Anda selalu melihat hal yang sama.

Aplikasi ini, untuk ponsel atau komputer Anda, plus gateway untuk desktop Linux yang ingin Anda kendalikan.

⚠️ Gunakan dengan risiko Anda sendiri. TrXi-Ctrl dan trixie-gateway adalah perangkat lunak bebas yang memberi perangkat yang dipasangkan kendali kuat atas komputer Anda, termasuk menjalankan perintah sebagai pengguna gateway (sering kali root). Anda bertanggung jawab atas setiap perintah yang Anda kirim, untuk menjaga gateway tetap di luar internet terbuka dan kode pemasangan Anda tetap privat, dan untuk hanya mengendalikan mesin yang Anda berwenang untuk mengendalikannya. CHAMELEON-AI-AGENT LTD dan penulis tidak menerima tanggung jawab apa pun atas kerugian akibat perintah yang merusak, berbagi sumber daya melalui internet, atau pengaturan yang tidak didukung — lihat Ketentuan §8A. Apa yang telah kami perbaiki dan rencanakan untuk diperbaiki, diukur terhadap ISO/IEC 27001: tinjauan keamanan (kerja penyelarasan, bukan sertifikasi).

Instal aplikasinya

Belum ada build yang ditandatangani oleh Apple atau Microsoft, jadi setiap sistem bertanya sekali apakah Anda mempercayainya

🤖

Android

Unduh APK di ponsel dan buka. Android meminta izin untuk mengizinkan pemasangan dari browser atau pengelola file Anda saat pertama kali — izinkan, lalu Instal. Sebagian besar ponsel dari sepuluh tahun terakhir memerlukan APK arm64; gunakan armv7 hanya pada ponsel 32-bit lama. Pembaruan selanjutnya dapat langsung dari gateway: Pembaruan tab.

🍏

iPhone & iPad

Build iOS tidak ditandatangani, jadi di-sideload: instal Secara sampingan atau Toko Alt di komputer, sambungkan iPhone, masukkan .ipa dan masuk dengan Apple ID apa pun. Lalu di iPhone: Pengaturan → Umum → VPN & Manajemen Perangkat → percayai Apple ID Anda. Dengan Apple ID gratis, aplikasi harus di-sideload ulang setiap 7 hari.

🪟

jendela 10/11

Ekstrak unduhan di mana saja (misalnya C:\Programs\TrXi-Ctrl) dan jalankan trxi_ctrl.exe. SmartScreen mengatakan "Windows melindungi PC Anda" saat pertama kali: Info selengkapnya → Jalankan saja. Simpan file bersama-sama — .exe membutuhkan DLL dan folder data di sebelahnya.

🍎

macOS

Buka .dmg dan seret TrXi-Ctrl ke Aplikasi. Pertama kali, klik kanan aplikasi → Membuka → Buka (klik dua kali diblokir karena tidak dinotarisasi). Jika macOS masih menolak, Pengaturan Sistem → Privasi & Keamanan → Buka Saja.

🐧

Linux

Memerlukan GTK 3 dan libmpv: di Debian/Ubuntu sudo apt install libgtk-3-0 libmpv2. Lalu tar -xzf TrXi-Ctrl-1.1.0-linux.tar.gz dan jalankan ./bundle/trxi_ctrl. Jaga bundle folder tetap bersama.

🔗

Pasangkan dengan desktop Anda

Di desktop Linux yang menjalankan gateway, buka http://localhost:8772/admin (atau Gateway Manager). Ponsel dan Mac: aplikasi → Pengaturan → ikon pemindai QR → pindai QR, atau ketuk ikon gambar untuk membuka gambar QR yang dikirim seseorang melalui email kepada Anda. Windows dan Linux: masukkan alamat gateway dan kode pemasangan yang ditampilkan di bawah QR. Kode hanya berlaku sekali dan bertahan 10 menit. Kedua perangkat harus berada di jaringan Tailscale atau LAN yang sama.

Instal gateway

Di mesin Debian Trixie (atau Linux yang kompatibel) yang ingin Anda kendalikan

# Linux — biner mandiri, tidak ada lagi yang perlu diinstal # (v0.2.0-test2 mendahului perbaikan keamanan Oktober; untuk itu, jalankan dari sumber — lihat di bawah) curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # lalu di aplikasi ponsel: Settings → Gateway URL → http://<this-machine's-tailscale-or-LAN-ip>:8772 # atau ketuk "Discover Peers" jika Anda berdua berada di jaringan Tailscale yang sama

Lebih suka Python? git clone https://github.com/cou645/trixie-gateway.git, lalu pip install -r requirements.txt Dan python3 gateway.py --port 8772. Dokumentasi instalasi lengkap, termasuk menjalankannya sebagai layanan systemd, ada di repositori README.md.

🧪 Build uji Windows & macOS ada di halaman rilis (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). Aplikasi ini tidak ditandatangani, jadi Windows SmartScreen akan mengatakan "penerbit tidak dikenal" (Info selengkapnya → Jalankan saja) dan macOS akan memblokir peluncuran pertama (klik kanan → Buka). Harap laporkan apa yang rusak.
