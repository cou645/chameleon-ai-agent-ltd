TrXi-Ctrl

Kontrol jarak jauh gratis untuk desktop Linux Anda — Bluetooth, firewall, audio, media, jendela, terminal, berbagi layar, clipboard bersama, dan obrolan AI, semua dari ponsel Anda — plus, di ponsel yang di-root, hotspot VPN dan penyimpanan massal USB. Dibuat untuk Debian Trixie; berfungsi di sebagian besar desktop Linux X11 lainnya juga.

🆓 Gratis & terbuka 🐧 Hanya Linux / X11 🔌 14 layar kontrol (+2 di ponsel yang di-root) 🤖 Server MCP disertakan 🔒 Jaringan Anda, tanpa relay cloud

Apa yang dilakukannya

Satu aplikasi ponsel, satu daemon gateway di desktop Anda

🖥️

Sistem & lapisan

Statistik CPU/memori/termal langsung dan pengalihan lapisan AUFS, langsung dari desktop.

📶

Jaringan & Wi-Fi

Antarmuka, alamat, pemindaian dan koneksi Wi-Fi — termasuk penemuan peer Tailscale untuk menemukan gateway Anda secara otomatis.

🔵

Bluetooth

Daya, dapat ditemukan/dipasangkan, pindai, pasangkan, sambungkan, percayai, hapus — kontrol adaptor penuh.

🛡️

tembok api

Lihat dan edit aturan dan rantai iptables, terapkan preset, dari ponsel Anda.

🔊

Audio

Volume, mute, daftar sink — dan streaming output audio desktop ke speaker ponsel Anda melalui WebRTC.

🎬

Media

Play/pause/seek/volume sungguhan untuk Chameleon Media Center dan pemutar berbasis MPV, melalui soket IPC milik mpv sendiri — bukan sekadar daftar file statis.

📺

CMC Langsung

Tonton Chameleon Media Centersiaran langsung di ponsel Anda — pilih Low latency (MPEG-TS) atau Smooth (HLS) untuk koneksi lemah — lihat apakah sedang live, sumbernya dan berapa banyak yang menonton, dan salin tautan agar siapa pun dapat menonton di browser.

🪟

Windows & desktop

Daftar, fokus, tutup, perkecil, perbesar, susun jendela dan ganti desktop virtual.

📲

Desktop jarak jauh

Berbagi layar penuh melalui WebRTC dengan sentuh-ke-mouse dan input keyboard — lihat dan kendalikan desktop Anda dari mana saja di jaringan Anda. Berfungsi penuh: ketukan, seret, dan ketukan tombol yang Anda kirim muncul di desktop hampir seketika. Keterlambatan yang Anda perhatikan ada pada pembaruan layar yang datang dari desktop ke ponsel Anda, bukan pada input Anda.

📋

Papan klip bersama

PC adalah hub: setiap ponsel mendorong papan klipnya ke sana — langsung ke papan klip PC sendiri, siap ditempel — dan layar Clipboard mencantumkan entri terbaru setiap perangkat. Ketuk satu untuk menyalinnya ke ponsel ini. Tidak ada yang dibaca dari atau ditulis ke papan klip ponsel Anda di latar belakang, hanya saat Anda mengetuk.

⌨️

Terminal

Shell sungguhan, dijalankan dari ponsel Anda.

🤖

Obrolan AI

Bicaralah dengan penyedia AI mana pun yang telah Anda konfigurasi di gateway — DeepSeek, OpenAI, Anthropic dan lainnya.

Ponsel yang di-root

Dua layar tambahan muncul otomatis saat ponsel memiliki root (Magisk)

🔐

VPN hotspot

Bagikan node keluar Tailscale ponsel ke setiap perangkat di hotspot Wi-Fi-nya — laptop, TV, dan konsol mendapatkan VPN tanpa menginstal apa pun. Perutean diterapkan ulang secara otomatis jika hotspot atau Tailscale restart, dan skrip boot dapat memulihkan semuanya setelah reboot. Dibuat untuk ponsel yang dibiarkan terpasang sebagai router: batas pengisian daya, jaga Tailscale dari optimasi baterai, dan Always-on VPN.

💾

Penyimpanan massal USB

Colokkan ponsel ke PC mana pun dan ponsel muncul sebagai drive USB. Buat image disk hingga 256 GB dalam hitungan detik — FAT32 (dibaca semua OS), ext4 (tanpa batas file 4 GB), atau disk GPT yang dapat di-boot dengan partisi EFI sehingga laptop dapat boot dari ponsel — lalu bagikan sebagai baca-tulis atau hanya-baca, atau buka di ponsel itu sendiri. Anda juga dapat menyerahkan kartu SD ponsel atau drive USB ke PC. ADB tetap terhubung selama berbagi.

Gerbang

trixie-gateway — sisi desktop, satu biner mandiri

📦

Satu biner, tanpa perlu Python

Unduh satu executable mandiri — tanpa Python, pip, atau venv di mesin. Dibangun di atas aiohttp + aiortc, dan sumbernya masih ada di GitHub jika Anda lebih suka menjalankannya dari Python. Berjalan mandiri atau sebagai layanan systemd, mendengarkan di alamat Tailscale/LAN Anda.

🔌

~120 endpoint REST

Setiap fitur aplikasi ponsel di atas, plus yang kompatibel dengan OpenAI /v1/chat/completions yang merutekan ke penyedia AI mana pun yang Anda konfigurasikan.

🧩

Server MCP disertakan

media_mcp_server.py mengekspos kontrol media (status, putar, jeda, cari, volume, buka, jelajah) sebagai alat MCP melalui stdio JSON-RPC — data sesi dan jalur kontrol yang sama dengan yang digunakan aplikasi ponsel, sehingga agen AI dan ponsel Anda selalu melihat hal yang sama.

Instal gateway

Di mesin Debian Trixie (atau Linux yang kompatibel) yang ingin Anda kendalikan

# Linux — biner mandiri, tidak ada lagi yang perlu diinstal curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # lalu di aplikasi ponsel: Pengaturan → URL Gateway → http://<ip-tailscale-atau-LAN-mesin-ini>:8772 # atau ketuk "Discover Peers" jika Anda berdua berada di jaringan Tailscale yang sama

Lebih suka Python? git clone https://github.com/cou645/trixie-gateway.git, lalu pip install -r requirements.txt Dan python3 gateway.py --port 8772. Dokumentasi instalasi lengkap, termasuk menjalankannya sebagai layanan systemd, ada di repositori README.md.

🧪 Build uji Windows & macOS ada di halaman rilis (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). Aplikasi ini tidak ditandatangani, jadi Windows SmartScreen akan mengatakan "penerbit tidak dikenal" (Info selengkapnya → Jalankan saja) dan macOS akan memblokir peluncuran pertama (klik kanan → Buka). Harap laporkan apa yang rusak.
