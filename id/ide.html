Chameleon AI IDE

Editor kode tempat AI yang melakukan pekerjaannya — ia membaca file Anda, membuat perubahan, menjalankan perintah, dan memeriksa hasilnya. Anda meninjau dan menyetujui.

🧠 AI mengedit kode Anda secara langsung 🎙️ Masukan suara, jawaban lisan 🔀 Lihat perbedaan sebelum Anda menerima 🔌 Sembilan penyedia AI, tukar kapan saja 🔒 Berjalan lokal, kunci tetap milik Anda

Apa yang membuatnya berbeda

Kebanyakan editor AI hanya memberi saran. Yang satu ini mengoperasikan editornya.

🤖

AI membuat edit

Membaca file sekali, lalu membuat perubahan presisi sebanyak yang diperlukan tanpa membaca ulang. Edit menargetkan teks yang tepat, bukan nomor baris, sehingga tidak bergeser saat file berubah. File baru ditulis secara utuh — dengan cadangan otomatis untuk apa pun yang digantinya.

💻

Ia menjalankan perintah dan membaca hasilnya

AI menjalankan perintah shell di terminal bawaan, menunggu setiap hasil, memeriksa kode keluar, dan memutuskan langkah selanjutnya. Pekerjaan nyata di shell langsung — bukan potongan salin-tempel.

🛡️

Aman secara bawaan

Semua yang dibaca AI dari file, terminal, atau halaman web dipagari sebagai data, bukan sebagai instruksi — file berbahaya tidak dapat membajak sesi. Setiap perubahan yang dibuatnya dicatat dengan stempel waktu dan ID sesi, sehingga Anda memiliki riwayat lengkap tentang apa yang terjadi.

🔀

Tinjau sebelum Anda menerima

Satu klik menampilkan perbedaan berkode warna dari perubahan AI terhadap simpanan terakhir Anda. Terima, lanjutkan mengedit, atau batalkan.

🎙️

Bebas genggam

Diktekan pertanyaan atau seluruh prompt dengan speech-to-text di perangkat, dan jawaban akan dibacakan dengan suara alami — tidak ada yang dikirim ke layanan transkripsi cloud. Atau aktifkan mode suara langsung (GPT Realtime) dan lakukan percakapan lisan dua arah dengan AI.

🔌

Bawa AI Anda sendiri

DeepSeek, OpenAI, Claude, Groq, Mistral, Kimi — ganti penyedia di tengah proyek. Jalankan model secara lokal melalui Ollama atau LM Studio tanpa biaya sama sekali. Claude Code berjalan sebagai proses langsung di dalam terminal.

🧩

Mode kerja yang dapat ditumpuk

Nyalakan mode yang Anda butuhkan — perbaikan kode, penulisan akademis, obrolan biasa — dan gabungkan semuanya. Perkiraan biaya berjalan ditampilkan sebelum Anda mengirim apa pun.

🗂️

Editor asli di bawahnya

Pengeditan multi-tab dengan undo per tab dan penyorotan sintaks, pohon file proyek dan navigator kode, serta obrolan streaming yang menjaga jendela tetap responsif saat perintah berjalan di latar belakang. Tinjauan kode AI sesuai permintaan menandai masalah langsung di editor dengan garis bawah dan tip saat kursor diarahkan.

🖼️

Gambar di obrolan, dua arah

Kirimkan AI PNG, JPEG, GIF, atau WebP — tangkapan layar, diagram, foto papan tulis — dan AI akan melihatnya. AI juga dapat menjawab dengan gambar: grafik SVG dan PNG sebaris dalam balasannya dirender langsung di obrolan, bukan sebagai dinding kode.

🎨

Studio Media

Tab khusus untuk pembuatan gambar dan video AI: formulir prompt untuk masing-masing, riwayat pekerjaan Anda (video bisa memakan waktu beberapa menit, jadi tetap berjalan di latar belakang), dan panel pratinjau untuk menyimpan atau menyalin hasilnya.

🖥️

Penggunaan Komputer

Biarkan AI mengoperasikan desktop itu sendiri — AI melihat layar dan menggunakan mouse serta keyboard untuk menjalankan tugas di aplikasi apa pun, bukan hanya di dalam editor.

🔗

Server MCP untuk agen AI

Server Model Context Protocol yang disertakan memungkinkan agen AI seperti Claude Code mengendalikan IDE dan Kameleon Presenter secara langsung.
