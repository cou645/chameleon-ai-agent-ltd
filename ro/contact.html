Întrebări comune

Pot să încerc?

Nu este încă disponibil public. Scrieți-ne un e-mail pentru o demonstrație și pentru a fi anunțați când se lansează.

Funcționează offline?

În mare parte. Editorul, contabilitatea, instrumentele de prezentare și cele pentru șoferi rulează local. Funcțiile AI necesită internet pentru un furnizor cloud — sau funcționează offline cu un model local prin Ollama sau LM Studio.

Care platforme?

Linux este platforma principală; Windows și macOS sunt acceptate. Telefonul însoțitor este Android și se împerechează cu desktopul prin propria rețea privată.
