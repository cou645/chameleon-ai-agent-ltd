TrXi-Ctrl

Control de la distanță gratuit pentru desktopul tău Linux — Bluetooth, firewall, audio, media, ferestre, terminal, partajare ecran, clipboard partajat și chat AI, toate de pe telefonul tău — plus, pe telefoanele rootate, hotspot VPN și stocare de masă USB. Creat pentru Debian Trixie; funcționează și pe majoritatea celorlalte desktopuri Linux X11.

🆓 Gratuit și open 🐧 Doar Linux / X11 🔌 14 ecrane de control (+2 pe telefoanele rootate) 🤖 Server MCP inclus 🔒 Rețeaua ta, fără relay cloud

Ce face

O aplicație pe telefon, un daemon gateway pe desktopul tău

🖥️

Sistem și straturi

Statistici live CPU/memorie/termice și comutarea straturilor AUFS, direct de pe desktop.

📶

Rețea și Wi-Fi

Interfețe, adrese, scanare și conectare Wi-Fi — inclusiv descoperirea peerilor Tailscale pentru a-ți găsi automat gateway-ul.

🔵

Bluetooth

Alimentare, detectabil/împerechebil, scanare, împerechere, conectare, încredere, eliminare — control complet al adaptorului.

🛡️

Paravan de protecție

Vizualizează și editează regulile și lanțurile iptables, aplică presetări, de pe telefonul tău.

🔊

Audio

Volum, mut, listă sink — și transmite ieșirea audio a desktopului către difuzorul telefonului tău prin WebRTC.

🎬

Media

Play/pause/seek/volume real pentru Chameleon Media Center și playere bazate pe MPV, prin propriul socket IPC al mpv — nu doar o listă statică de fișiere.

📺

CMC Live

Urmărește Chameleon Media Centertransmisia live pe telefonul tău — alege Low latency (MPEG-TS) sau Smooth (HLS) pentru conexiuni slabe — vezi dacă este live, sursa sa și câți urmăresc, și copiază un link pentru ca oricine să poată urmări într-un browser.

🪟

Windows și desktopuri

Listează, focalizează, închide, minimizează, maximizează, aranjează ferestrele în mozaic și comută desktopurile virtuale.

📲

Desktop la distanță

Partajare completă de ecran prin WebRTC cu atingere-în-mouse și introducere de la tastatură — vezi și controlează-ți desktopul de oriunde din rețeaua ta. Complet funcțional: atingările, tragerile și apăsările de taste pe care le trimiți apar pe desktop aproape imediat. Orice întârziere pe care o observi este în actualizările ecranului care vin de la desktop la telefonul tău, nu în introducerea ta.

📋

Clipboard partajat

PC-ul este hubul: fiecare telefon își trimite clipboardul acolo — direct în clipboardul propriu al PC-ului, gata de lipit — iar ecranul Clipboard listează cea mai recentă intrare a fiecărui dispozitiv. Atinge una pentru a o copia pe acest telefon. Nimic nu este citit sau scris în clipboardul telefonului tău în fundal, doar când atingi.

⌨️

Terminal

Un shell real, rulat de pe telefonul tău.

🤖

Chat AI

Vorbește cu orice furnizor AI pe care l-ai configurat pe gateway — DeepSeek, OpenAI, Anthropic și altele.

Telefoane cu root

Două ecrane suplimentare apar automat când telefonul are root (Magisk)

🔐

VPN hotspot

Partajează nodul de ieșire Tailscale al telefonului cu fiecare dispozitiv din hotspotul său Wi-Fi — laptopurile, televizoarele și consolele primesc VPN-ul fără să instaleze nimic. Rutarea se reaplică automat dacă hotspotul sau Tailscale repornește, iar un script de boot poate readuce totul după o repornire. Creat pentru un telefon lăsat conectat ca router: limită de încărcare, ține Tailscale în afara optimizării bateriei și Always-on VPN.

💾

Stocare de masă USB

Conectează telefonul la orice PC și acesta apare ca unitate USB. Creează o imagine de disc de până la 256 GB în câteva secunde — FAT32 (citită de orice sistem de operare), ext4 (fără limita de fișier de 4 GB) sau un disc GPT bootabil cu partiție EFI, astfel încât un laptop să poată porni de pe telefon — apoi partajeaz-o cu citire-scriere sau doar citire, sau deschide-o pe telefonul însuși. Poți, de asemenea, să predai PC-ului cardul SD al telefonului sau o unitate USB. ADB rămâne conectat în timpul partajării.

Gateway-ul

trixie-gateway — partea de desktop, un singur binar autonom

📦

Un singur binar, fără Python necesar

Descarcă un singur executabil autonom — fără Python, pip sau venv pe mașină. Construit pe aiohttp + aiortc, iar sursa este încă pe GitHub dacă preferi să îl rulezi din Python. Rulează independent sau ca serviciu systemd, ascultând pe adresa ta Tailscale/LAN.

🔌

~120 de endpoint-uri REST

Fiecare funcție a aplicației de telefon de mai sus, plus unul compatibil cu OpenAI /v1/chat/completions care rutează către orice furnizor AI pe care îl configurezi.

🧩

Server MCP inclus

media_mcp_server.py expune controlul media (stare, redare, pauză, căutare, volum, deschidere, navigare) ca instrumente MCP prin stdio JSON-RPC — aceleași date de sesiune și cale de control pe care le folosește aplicația de telefon, astfel încât un agent AI și telefonul tău văd mereu același lucru.

Instalează gateway-ul

Pe mașina Debian Trixie (sau Linux compatibil) pe care vrei să o controlezi

# Linux — binar autonom, nimic altceva de instalat curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # apoi în aplicația de telefon: Setări → URL gateway → http://<ip-tailscale-sau-LAN-al-acestei-mașini>:8772 # sau apasă "Discover Peers" dacă sunteți amândoi în aceeași rețea Tailscale

Preferi Python? git clone https://github.com/cou645/trixie-gateway.git, apoi pip install -r requirements.txt şi python3 gateway.py --port 8772. Documentația completă de instalare, inclusiv rularea ca serviciu systemd, se află în depozitul README.md.

🧪 Versiuni de test pentru Windows și macOS sunt pe pagina de versiuni (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). Nu sunt semnate, așa că Windows SmartScreen va spune "editor necunoscut" (Mai multe informații → Rulează oricum), iar macOS va bloca prima lansare (clic dreapta → Deschide). Te rugăm să raportezi ce se strică.
