TrXi-Ctrl

Linuxデスクトップ用の無料リモートコントロール — Bluetooth、ファイアウォール、オーディオ、メディア、ウィンドウ、ターミナル、画面共有、共有クリップボード、AIチャットを、すべてスマートフォンから — さらに、root化したスマートフォンでは、VPNホットスポットとUSBマスストレージも。Debian Trixie向けに構築。他のほとんどのX11 Linuxデスクトップでも動作します。

🆓 無料でオープン 🐧 Linux / X11のみ 🔌 14のコントロール画面（root化したスマートフォンでは+2） 🤖 MCP サーバー同梱 🔒 あなたのネットワーク、クラウドリレーなし

動作内容

スマートフォンアプリ1つ、デスクトップ上のゲートウェイデーモン1つ

🖥️

システムとレイヤー

ライブCPU/メモリ/温度統計とAUFSレイヤーの切り替えを、デスクトップから直接。

📶

ネットワークとWi-Fi

インターフェース、アドレス、Wi-Fiスキャンと接続 — Tailscaleピア検出によるゲートウェイの自動検出も含む。

🔵

ブルートゥース

電源、検出可能/ペアリング可能、スキャン、ペアリング、接続、信頼、削除 — アダプターの完全制御。

🛡️

ファイアウォール

iptablesのルールとチェーンを表示・編集し、プリセットを適用、スマートフォンから。

🔊

オーディオ

音量、ミュート、シンク一覧 — そしてデスクトップの音声出力をWebRTC経由でスマートフォンのスピーカーにストリーミング。

🎬

u30e1u30c7u30a3u30a2

本物の再生/一時停止/シーク/音量： Chameleon Media Center およびMPVベースのプレーヤー向け。mpv自身のIPCソケット経由 — 単なる静的なファイル一覧ではありません。

📺

CMCライブ

視聴 Chameleon Media Centerのライブストリームをスマートフォンで — 弱い接続には低遅延（MPEG-TS）またはスムーズ（HLS）を選択 — ライブかどうか、ソース、視聴者数を確認し、誰でもブラウザで視聴できるリンクをコピーできます。

🪟

Windowsとデスクトップ

ウィンドウの一覧表示、フォーカス、閉じる、最小化、最大化、タイル表示、仮想デスクトップの切り替え。

📲

リモートデスクトップ

WebRTCによる全画面共有とタッチ・トゥ・マウスおよびキーボード入力 — ネットワーク上のどこからでもデスクトップを表示・操作できます。完全に機能します：送信したタップ、ドラッグ、キー入力はほぼ即座にデスクトップに反映されます。気づく遅延は、デスクトップからスマートフォンに戻ってくる画面更新によるもので、入力によるものではありません。

📋

共有クリップボード

PCがハブです：各スマートフォンはクリップボードをそこへ送信します — PC自身のクリップボードに直接、貼り付け可能な状態で — そしてクリップボード画面には各デバイスの最新エントリが一覧表示されます。1つをタップするとこのスマートフォンにコピーされます。バックグラウンドでスマートフォンのクリップボードから読み取ったり書き込んだりすることはなく、タップしたときだけ行います。

⌨️

ターミナル

スマートフォンから実行する本物のシェル。

🤖

AIチャット

ゲートウェイで設定した任意のAIプロバイダーと会話 — DeepSeek、OpenAI、Anthropicなど。

root化されたスマートフォン

スマートフォンがroot化（Magisk）されていると、2つの追加画面が自動的に表示されます

🔐

ホットスポットVPN

スマートフォンのTailscale出口ノードを、そのWi-Fiホットスポット上のすべてのデバイスと共有します — ノートPC、テレビ、ゲーム機は何もインストールせずにVPNを利用できます。ホットスポットまたはTailscaleが再起動するとルーティングは自動的に再適用され、起動スクリプトで再起動後にすべてを復元できます。ルーターとして接続したままにするスマートフォン向けに設計：充電制限、Tailscaleをバッテリー最適化から除外、常時接続VPN。

💾

USBマスストレージ

スマートフォンを任意のPCに接続するとUSBドライブとして表示されます。最大256 GBのディスクイメージを数秒で作成 — FAT32（すべてのOSが読み取り可能）、ext4（4 GBのファイル制限なし）、またはEFIパーティション付きの起動可能なGPTディスクでノートPCがスマートフォンから起動可能 — その後、読み書きまたは読み取り専用で共有するか、スマートフォン自体で開きます。スマートフォンのSDカードやUSBドライブをPCに渡すこともできます。共有中もADBは接続されたままです。

ゲートウェイ

trixie-gateway — デスクトップ側、単一の自己完結型バイナリ

📦

単一バイナリ、Python不要

単一の自己完結型実行ファイルをダウンロード — マシンにPython、pip、venvは不要。aiohttp + aiortcで構築されており、Pythonから実行したい場合のためにソースは今もGitHubにあります。単独で、またはsystemdサービスとして実行され、Tailscale/LANアドレスで待ち受けます。

🔌

約120のRESTエンドポイント

上記のすべてのスマートフォンアプリ機能に加え、OpenAI互換の /v1/chat/completions 設定した任意のAIプロバイダーにルーティングします。

🧩

MCPサーバー同梱

media_mcp_server.py メディア制御（ステータス、再生、一時停止、シーク、音量、開く、閲覧）をstdio JSON-RPC経由のMCPツールとして公開します — スマートフォンアプリが使用するのと同じセッションデータと制御パスなので、AIエージェントとスマートフォンは常に同じものを見ます。

互換性

Debian Trixie 向けに構築 — 他でどこで動作するかについて正直に

プラットフォームステータス理由
Debian トリクシー✓ ここで開発・テスト済み—
Fatdog64 / Puppy Linux ファミリー✓ 動作するはずLayers 機能はどちらの下でも union-fs ブランチを検出します /aufs （Fatdog64 派生、このマシンを含む）または /initrd （標準 Puppy）を自動的に — /initrd パスは実際の Puppy インストールに対してテストされておらず、実地検証ではなく文書化された慣例に基づいています
その他の X11 Linux デスクトップ✓ 動作するはずBlueZ、iptables、PulseAudio/PipeWire（pactl 互換）、および X11 セッションが必要です（Wayland のみのデスクトップはサポートされていません — wmctrl/xdotool X11 が必要）
Windows 11🧪 実験的なテストビルド画面共有、マウス/キーボード、ウィンドウ一覧、音量、ターミナルは Windows 向けに実装されています。バイナリは自動 CI でビルドおよび起動しますが、 実際の Windows マシンではまだ実行されていません — 粗削りな部分を想定してください。Bluetooth、ファイアウォール、レイヤー、明るさ、ネットワーク、Media Center は Linux 専用のままで、応答します 501
macOS (インテルおよび Apple シリコン)🧪 実験的なテストビルドWindows と同じ機能セットで、Quartz、AVFoundation、および osascriptを使用します。両方のアーキテクチャで CI でビルドおよび起動しますが、 実際の Mac では未テストです。アプリは署名されておらず、macOS は画面収録とアクセシビリティの許可を求めます

ダウンロード 無料

スマホアプリ（Android）+ デスクトップゲートウェイ。どちらもオープン、どちらも無料。

⬇ APKをダウンロード ⬇ Linux用ゲートウェイ Windows & macOS テストビルド 🧪 GitHubでゲートウェイを見る →

ゲートウェイをインストール

制御したいDebian Trixie（または互換Linux）マシン上で

# Linux — スタンドアロンバイナリ、他にインストールするものはありません curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # その後スマホアプリで: 設定 → ゲートウェイURL → http://<このマシンのTailscaleまたはLANのIP>:8772 # または、両方が同じTailscaleネットワーク上にいる場合は「ピアを検出」をタップ

Pythonの方がいい？ git clone https://github.com/cou645/trixie-gateway.git、次に pip install -r requirements.txt そして python3 gateway.py --port 8772。systemdサービスとしての実行を含む完全なインストールドキュメントは、リポジトリの README.md.

🧪 Windows & macOS テストビルド はこちら リリースページ (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip)。これらは署名されていないため、Windows SmartScreen は「不明な発行元」と表示し（詳細情報 → 実行）、macOS は初回起動をブロックします（右クリック → 開く）。不具合があれば報告してください。
