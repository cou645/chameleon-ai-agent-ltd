Chameleon Media Center

mpv 上に構築された完全なデスクトップ メディア スタジオ — 再生、プレイリスト、Watch-as-you-go キャッシュ付きの YouTube および Bilibili 検索、ライブ ストリーミング、DVB-T/T2 TV、DVD/Blu-ray/CD、Bluetooth および USB オーディオ ルーティング、サウンド エフェクト、ビジュアライザー、ビデオ エディター、イコライザー、仮想 Web カメラ、マルチフォン Android ミラーリング、スケジューラー、ゲーム、スポーツ スコアボードを 1 つのアプリで実行できます。

🎞️ mpv搭載の再生 🔎 YouTube＆Bilibili検索 + 視聴キャッシュ 📡 ライブ DVB-T/T2/C/S/ATSC TV 💿DVD・Blu-ray・CD 🔵 Bluetooth Tx/Rx + USB ターンテーブル/ミキサー入力 📱 最大16台のスマホを同時にミラーリング 📷 バーチャルウェブカメラ + 4隅 PiP 📡 ブラウザ、YouTube、Twitch などへ配信 🤏 各スマホでピンチ/スクロールズーム ⏰ 予約録画とダウンロード 🎮 携帯電話をコントローラーとして使用するゲーム 🤖 MCP サーバー同梱

中身の紹介

13のタブ、1つのメディアエンジン

🎞️

ビデオパネル

mpvによる再生 — 幅広いフォーマット対応、スムーズなシーク、ワンクリックの全画面切り替え（またはF11）、プレイヤープロセスが予期せず終了した場合の自動復旧、そして再起動しても最後に選んだオーディオ出力デバイスを記憶し、デフォルトにリセットされません。低遅延のピクチャーインピクチャーオーバーレイは、再生中のものの四隅に最大4台のカメラ — 内蔵ウェブカメラまたは任意のスマートフォン — を配置します。再生中のストリームを録画したり、再生中のものをワンキーでダウンロードしたりできます。IntelグラフィックスではH.264、HEVC、VP9、AV1をGPUでデコードします — よりスムーズな再生と長いバッテリー寿命のためにCPUを約40%削減 — そしてGPUが処理できないものは自動的にソフトウェアにフォールバックします。

📃

プレイリスト

ドラッグ＆ドロップでの並べ替え、キューの管理、プレイリストのインポートと保存、ゴミ箱から削除済みプレイリストの復元。単一ファイルまたはフォルダ全体をサブフォルダごと追加できます。ファイルが存在しない項目 — 接続されていない USB ドライブ、整理して消したキャッシュ動画 — は戻るまでグレー表示になり、整理した動画はダブルクリックで再ダウンロードされます。

🔀

交換可能なパネル

動画を必要な場所に配置します。表示 → 動画 ⇄ プレイリスト（Ctrl+Shift+P）は動画を右列の上部に、プレイリストを左側に移動し、そこでは折りたたんでADBスマートフォンが左列の高さをすべて使えるようにできます。動画 ⇄ ウォッチリスト（Ctrl+Shift+W）は代わりに動画をプレイリストの下に配置します。入れ替えても再生はそのまま続き、選んだレイアウトは記憶され、全画面はどのレイアウトでも機能します。

🔎

検索と視聴キャッシュ

YouTubeまたはBilibiliを検索したり、TikTokクリエイターの最新動画を一覧表示したり、TikTok、Instagram、Facebook、Snapchat Spotlight、Douyinのリンクを貼り付けたりできます。結果はプレイリストの下の番号付きウォッチリストにキューイングされます。視聴したものは視聴しながらディスクに保存されます — 別途ダウンロードは不要 — なので次回の視聴はローカルコピーから再生され、途中まで視聴した動画は保存済みの量を表示し、次回に残りを補完します。保存した動画をメインプレイリストに移動し、アプリを閉じるときにどれを残すか削除するかを選べます。オプションのブラウザCookieは「ロボットではないことを確認してください」やサインインの壁を突破します。ダウンロードを縮小にチェックを入れると、完了した各ダウンロードまたは録画はGPUで最大720pのHEVCに再エンコードされます — 通常は元のサイズの約3分の1 — 結果が小さくならない場合は元を保持します。

📡

DVBテレビ

本物のデジタルテレビをスキャンして視聴 — DVB-T/T2、DVB-C、DVB-S/S2、ATSC — USBまたはPCIチューナーから直接。

💿

DVD / CD / ブルーレイ

光学ドライブ内のメディアを自動検出し、DVD-Video、Blu-ray、Audio CDトラックを再生 — 別途ディスクソフトは不要。

🔵

BT/USBオーディオ

再生を1台または複数のBluetoothスピーカーへ同時にルーティング（PulseAudio combine-sink）、アダプターを受信モードに切り替えてPC自体をBluetoothスピーカーにする、または取り込み 任意の 他のPulseAudioキャプチャソース — USBターンテーブル、MiniDiscデッキ、DJミキサー/コントローラー、オーディオインターフェース — を再生とVisualizerへ直接。すべて1つのInput Sourcesチェックリストから。

📱

ADBフォン — 同時に最大16台

1～16個の独立したパネルを好きなだけの列数で並べたグリッド — その数のAndroidスマートフォンを同時にミラーリングして操作できます。それぞれに専用の画面、オーディオルーティング、入力があります。ピンチ（このボックスにはタッチスクリーンがあります）またはスクロールホイールで任意のスマートフォンの画面にズームインし、Shift+ドラッグでパンします。マウス、スタイラス、タッチ、または物理キーボードで直接タップ、スワイプ、入力できます — デバイスごとに持続するシェルが、キーストロークごとに新しい接続コストを払う代わりに、すべての入力をリアルタイムに保ちます。ワンクリックの「ワイヤレス接続」でUSB接続のスマートフォンを自動的にadb-over-wifiに切り替えるか、スマートフォンのペアリングQRコードをスキャンしてWi-Fiでペアリングします。任意のスマートフォンにファイルをプッシュおよびプルでき、スリープ中のスマートフォンはストリーミング開始前に起こされます。ミラーは低遅延で動作します — スマートフォンの画面は利用可能な場合はGPUでデコードおよびスケーリングされます — そして各パネルにはA/V同期コントロールがあり、スマートフォンのPCオーディオをちょうど適切なミリ秒数だけ遅らせるので、音と映像が一致します。「画面オフ」はPCから視聴および操作を続けながらスマートフォン自体のディスプレイを消灯し、アプリを閉じると各スマートフォンのオーディオと画面がきれいに通常に戻ります。

📷

仮想カメラ

あらゆるビデオ通話アプリ、ブラウザ、OBSが選択できる「CMC PC Webcam」デバイス — 内蔵カメラまたは接続された任意のフォンのカメラを入力し、通話中でもアプリがデバイスを失うことなくソースを切り替え。各フォンパネルにも専用の仮想カメラが付きます。

📡

ライブストリーム

カメラまたはビデオパネルをLANまたはTailscale上の任意のブラウザにストリーミング（HLSプレーヤーページ）し、さらにTrXi-Ctrl、VLC、mpv用の低遅延フィードも提供 — 1回のエンコードから多数の視聴者 — またはYouTube Live、Facebook Live、Twitch、WeChat Channels、任意のRTMPサーバーにプッシュします。Intelグラフィックスでは、ストリームはCPUではなくGPUでエンコードされます。

🔗

共有と検出

同じネットワーク上のCMCは自動的に互いを見つけ、グループコードでプレイリスト — ローカルファイルを含む — を他のCMCと共有します。

🔔

サウンドエフェクト

サッカーのキック、ゴールの歓声、ゲームで使用される群衆の音など、プレイ中やストリーミング中にオンザフライのオーディオキューを提供するサウンドボード。

🌈

ビジュアライザー

現在再生中のあらゆるものに対応するリアルタイムのオーディオリアクティブビジュアル。

✂️

動画エディター

フレーム精度のビデオ エディター: フレーム番号または再生フレームからインとアウトを設定し、カットします (セクションを保持するか、セクションを削除して残りを結合します)。メモやサウンドからビデオ、画像、タイトル カードを追加し、クロスフェード、白黒へのディップ、ディゾルブ、ワイプ、スライド、アイリス、ズーム、ぼかしなどの 14 のトランジションを使用して順番にドラッグします。 3 つのオーディオ トラック (クリップ独自のサウンド、音楽、サウンド エフェクト) をミックスし、それぞれに独自のボリュームとプレビュー上でボリューム グラフを作成します。字幕が焼き付けられているか、切り替え可能です。元に戻すとやり直し。エクスポートは、利用可能な場合、GPU のハードウェア エンコーダ上でバックグラウンドで実行されます。

⏰

スケジュール

時間と曜日、または 1 回のジョブを設定します。ファイルまたはストリームの再生、停止、ストリームまたは DVB チャンネルの長時間録画、YouTube 検索の上位結果の取得、チャンネルまたはプレイリストから新しいビデオのみのダウンロード、何かが動いたときのみ Web カメラを録画 (各イベントの前後数秒)、または任意のコマンドの実行。ジョブは CMC が開いているときに実行され、CMC が閉じているジョブの時間に CMC 自体を開始できます。各ジョブは、別の国でのみ利用可能なソースに対して、Tailscale 出口ノードを通過できます。

🧩

プラグイン

X11 または mpvpaper を使用して Wayland で、デスクトップの壁紙としてビデオ (現在のビデオまたは任意のファイル) を再生します。 [プラグイン] タブには、1 つのビデオ内の複数の A-B ループ セクションなど、他の作成者からのオプションの追加機能と、ライセンス、それらを入手するためのリンク、およびそれらがインストールされているかどうかもリストされます。サードパーティ製のものは何もバンドルされていません。

🎮

ゲーム

メディアの再生中にプレイできるボード、カード、テーブル ゲームが含まれる [ゲーム] タブ: チェス、バックギャモン、囲碁、クロンダイク ソリティア、麻雀ソリティア、戦艦、三目並べ、四角形 (ドットとボックス)、サイコロ、バウンティ ヘイスト フットボール。コンピュータを選択したレベル (チェスの場合は Stockfish、囲碁の場合は GNU Go)、1 つの画面で 2 人でプレイするか、ネットワーク経由で友人とプレイします。すべてのゲームでスコアが記録されます。ターンベース ゲームは、リモート デスクトップを介してどこからでもプレイできます。 TrXi-Ctrl。リアルタイム ゲームの場合、携帯電話がコントローラーになります。TrXi-Ctrl を実行している任意の数の携帯電話が Wi-Fi または USB ケーブル経由で参加し、それぞれにジョイスティック、ボタン、キックオフと一時停止、ライブ スコア、および振動が表示されます。

ロック、テーマ、環境設定

パターンでウィンドウをロックし（Ctrl+Alt+L）、テーマを切り替え、環境設定を行えます — AboutとHelpを内蔵。

📲

リモートコントロール

再生/一時停止/シーク/音量のすべての操作はmpv自身のIPCソケット経由で公開されており、 TrXi-Ctrl — 私たちの無料スマホアプリ — が直接通信して本物のトランスポート操作を実現します。単なるセッション一覧ではありません。スマホからセッションを閉じると、中途半端なプレイヤーを残さずアプリ全体がきれいに終了します。

🤖

MCPサーバー

バンドルされた Model Context Protocol サーバーが、再生ステータス、再生/一時停止/シーク/音量/開く、ライブラリ閲覧をツールとして公開します — これにより AI エージェントとあなたのスマートフォンは常に同じセッションを認識し、操作できます。

🖼️

PySide6 / Qt

ネイティブで応答性の高いデスクトップ UI — 他の Chameleon AI デスクトップアプリと同じ Python/Qt スタックの一部です。

🎬

mpv エンジン

mpv 独自のウィンドウ埋め込みと JSON IPC ソケットを介して組み込み — 多くの Linux メディアツールを支える、信頼性が高く広く使われている同じ再生エンジンで、ディスク再生用に libdvdnav/libdvdread/libcdio/libbluray があらかじめリンクされています。

🔊

PulseAudio ネイティブのオーディオルーティング

マルチデバイス出力は PulseAudio 自身の module-combine-sink を使用します。Bluetooth 受信や USB オーディオデバイスなど、あらゆるキャプチャソースは module-loopback を介してループされ、PulseAudio 自身の Bluetooth ポリシーがすでにルーティングを設定しているかどうかを先に確認し、それと競合することはありません。
