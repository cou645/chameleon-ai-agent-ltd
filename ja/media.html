Chameleon Media Center

mpvを基盤にした本格的なデスクトップメディアスタジオ — 再生、プレイリスト、視聴しながらキャッシュするYouTube＆Bilibili検索、ライブストリーミング、DVB-T/T2テレビ、DVD/Blu-ray/CD、Bluetooth＆USBオーディオルーティング、サウンドエフェクト、ビジュアライザー、動画エディター、イコライザー、仮想ウェブカメラ、マルチスマホAndroidミラーリングを1つのアプリで。

🎞️ mpv搭載の再生 🔎 YouTube＆Bilibili検索 + 視聴キャッシュ 📡 ライブ DVB-T/T2/C/S/ATSC TV 💿DVD・Blu-ray・CD 🔵 Bluetooth Tx/Rx + USB ターンテーブル/ミキサー入力 📱 最大16台のスマホを同時にミラーリング 📷 バーチャルウェブカメラ + 4隅 PiP 📡 ブラウザ、YouTube、Twitch などへ配信 🤏 各スマホでピンチ/スクロールズーム 🤖 MCP サーバー同梱

中身の紹介

13のタブ、1つのメディアエンジン

🎞️

ビデオパネル

mpv による再生 — 幅広いフォーマット対応、滑らかなシーク、ワンクリックの全画面切り替え（または F11）、プレイヤープロセスが予期せず終了した場合の自動復旧、そして再起動をまたいで最後に選んだオーディオ出力デバイスを記憶し、デフォルトにリセットしません。低遅延のピクチャーインピクチャーオーバーレイは、内蔵ウェブカメラや任意のスマホなど最大4台のカメラを、再生中の映像の四隅に配置します。再生中のストリームをワンキーで録画、または再生中のものをダウンロードできます。

📃

プレイリスト

ドラッグ＆ドロップでの並べ替え、キューの管理、プレイリストのインポートと保存、ゴミ箱から削除済みプレイリストの復元。単一ファイルまたはフォルダ全体をサブフォルダごと追加できます。ファイルが存在しない項目 — 接続されていない USB ドライブ、整理して消したキャッシュ動画 — は戻るまでグレー表示になり、整理した動画はダブルクリックで再ダウンロードされます。

🔎

検索と視聴キャッシュ

YouTube や Bilibili を検索し、TikTok クリエイターの最新動画を一覧表示し、TikTok、Instagram、Facebook、Snapchat Spotlight、Douyin のリンクを貼り付けます。結果はプレイリストの下の番号付きウォッチリストにキューします。視聴したものは視聴しながらディスクに保存されます — 別途ダウンロードは不要 — なので次回はローカルコピーから再生され、途中まで見た動画は保存済みの量を表示し、次回に残りを補完します。保存した動画をメインプレイリストに移動し、アプリを閉じるときに残すものや削除するものを選べます。オプションのブラウザ Cookie で「ロボットではないことを確認」やサインインの壁を突破できます。

📡

DVBテレビ

本物のデジタルテレビをスキャンして視聴 — DVB-T/T2、DVB-C、DVB-S/S2、ATSC — USBまたはPCIチューナーから直接。

💿

DVD / CD / ブルーレイ

光学ドライブ内のメディアを自動検出し、DVD-Video、Blu-ray、Audio CDトラックを再生 — 別途ディスクソフトは不要。

🔵

BT/USBオーディオ

再生を1台または複数のBluetoothスピーカーへ同時にルーティング（PulseAudio combine-sink）、アダプターを受信モードに切り替えてPC自体をBluetoothスピーカーにする、または取り込み 任意の 他のPulseAudioキャプチャソース — USBターンテーブル、MiniDiscデッキ、DJミキサー/コントローラー、オーディオインターフェース — を再生とVisualizerへ直接。すべて1つのInput Sourcesチェックリストから。

📱

ADBフォン — 同時に最大16台

1〜16個の独立パネルを好きな列数で並べたグリッド — その台数のAndroidフォンを同時にミラーリング・操作でき、それぞれに専用の画面、オーディオルーティング、入力があります。ピンチ（このボックスはタッチスクリーン対応）またはスクロールホイールで任意のフォン画面をズーム、Shift+ドラッグでパン。マウス、スタイラス、タッチ、または物理キーボードで直接タップ、スワイプ、入力 — デバイスごとに持続するシェルがすべての入力をリアルタイムに保ち、キーストロークごとに新たな接続コストを払う必要はありません。ワンクリックの「Connect Wireless」でUSB接続のフォンを自動的にadb-over-wifiへ切り替え、またはフォンのペアリングQRコードをスキャンしてWi-Fiでペアリング。任意のフォンへファイルをプッシュ/プルでき、スリープ中のフォンはストリーミング開始前に起こされます。

📷

仮想カメラ

あらゆるビデオ通話アプリ、ブラウザ、OBSが選択できる「CMC PC Webcam」デバイス — 内蔵カメラまたは接続された任意のフォンのカメラを入力し、通話中でもアプリがデバイスを失うことなくソースを切り替え。各フォンパネルにも専用の仮想カメラが付きます。

📡

ライブストリーム

カメラまたはビデオパネルをLANまたはTailscale上の任意のブラウザへストリーミング（HLSプレーヤーページ）し、さらにTrXi-Ctrl、VLC、mpv向けの低遅延フィードも — 1回のエンコードで多数の視聴者 — またはYouTube Live、Facebook Live、Twitch、WeChat Channels、任意のRTMPサーバーへプッシュ。

🔗

共有と検出

同じネットワーク上のCMCは自動的に互いを見つけ、グループコードでプレイリスト — ローカルファイルを含む — を他のCMCと共有します。

🔔

サウンドエフェクト

プレイ中や配信中に即座に使えるオーディオキュー用のサウンドボード。

🌈

ビジュアライザー

現在再生中のあらゆるものに対応するリアルタイムのオーディオリアクティブビジュアル。

✂️

動画エディター

フレーム単位で正確なクリップシーケンサー：プレイヤーからIn/Outフレームを設定し、クリップを並べ替え、音楽トラック（元の音声の下にミックス、または置き換え）と字幕（焼き込み、または切り替え可能なトラックとして）を追加し、バックグラウンドで書き出します。

🎚️

18バンドイコライザーとオーディオ/ビデオエフェクト

調整して保存できるプリセットで、部屋や気分に合わせてサウンドを形作れます — さらにオーディオエフェクトと専用のビデオエフェクトタブも。

✅

ノート

メディアのすぐ横に、入力または手書きのノート（スタイラス/タッチ対応）— 作業中の制作/セッションノートに便利です。

🔒

ロック、テーマ、環境設定

パターンでウィンドウをロックし（Ctrl+Alt+L）、テーマを切り替え、環境設定を行えます — AboutとHelpを内蔵。

📲

リモートコントロール

再生/一時停止/シーク/音量のすべての操作はmpv自身のIPCソケット経由で公開されており、 TrXi-Ctrl — 私たちの無料スマホアプリ — が直接通信して本物のトランスポート操作を実現します。単なるセッション一覧ではありません。スマホからセッションを閉じると、中途半端なプレイヤーを残さずアプリ全体がきれいに終了します。

🤖

MCPサーバー

バンドルされた Model Context Protocol サーバーが、再生ステータス、再生/一時停止/シーク/音量/開く、ライブラリ閲覧をツールとして公開します — これにより AI エージェントとあなたのスマートフォンは常に同じセッションを認識し、操作できます。

オープンな基盤の上に構築

PySide6 (Qt) デスクトップアプリ、mpv 再生エンジン

🖼️

PySide6 / Qt

ネイティブで応答性の高いデスクトップ UI — 他の Chameleon AI デスクトップアプリと同じ Python/Qt スタックの一部です。

🎬

mpv エンジン

mpv 独自のウィンドウ埋め込みと JSON IPC ソケットを介して組み込み — 多くの Linux メディアツールを支える、信頼性が高く広く使われている同じ再生エンジンで、ディスク再生用に libdvdnav/libdvdread/libcdio/libbluray があらかじめリンクされています。

🔊

PulseAudio ネイティブのオーディオルーティング

マルチデバイス出力は PulseAudio 自身の module-combine-sink を使用します。Bluetooth 受信や USB オーディオデバイスなど、あらゆるキャプチャソースは module-loopback を介してループされ、PulseAudio 自身の Bluetooth ポリシーがすでにルーティングを設定しているかどうかを先に確認し、それと競合することはありません。
