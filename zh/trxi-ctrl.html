已 Root 的手机

当手机具有 root（Magisk）时，会自动出现两个额外屏幕

🔐

热点 VPN

将手机的 Tailscale 出口节点共享给其 Wi-Fi 热点上的每台设备——笔记本电脑、电视和游戏机无需安装任何东西即可获得 VPN。如果热点或 Tailscale 重启，路由会自动重新应用，启动脚本可以在重启后恢复一切。专为作为路由器长期插电的手机而设计：充电限制、让 Tailscale 免于电池优化，以及始终开启的 VPN。

💾

USB 大容量存储

将手机插入任何 PC，它就会显示为 USB 驱动器。几秒钟内创建最大 256 GB 的磁盘映像——FAT32（所有操作系统都能读取）、ext4（无 4 GB 文件限制），或带有 EFI 分区的可启动 GPT 磁盘，以便笔记本电脑可以从手机启动——然后以读写或只读方式共享，或直接在手机上打开。你也可以将手机的 SD 卡或 USB 驱动器交给 PC。共享期间 ADB 保持连接。

网关

trixie-gateway — 桌面端，单个自包含二进制文件

📦

单个二进制文件，无需 Python

下载单个自包含可执行文件——机器上无需 Python、pip 或 venv。基于 aiohttp + aiortc 构建，如果你更愿意从 Python 运行，源代码仍在 GitHub 上。可独立运行或作为 systemd 服务运行，监听你的 Tailscale/LAN 地址。

🔌

约 120 个 REST 端点

上述所有手机应用功能，外加一个兼容 OpenAI 的 /v1/chat/completions 可路由到你配置的任何 AI 提供商。

🧩

包含 MCP 服务器

media_mcp_server.py 通过 stdio JSON-RPC 将媒体控制（状态、播放、暂停、跳转、音量、打开、浏览）作为 MCP 工具公开——与手机应用使用相同的会话数据和控制路径，因此 AI 代理和你的手机始终看到相同的内容。

兼容性

专为 Debian Trixie 打造 — 坦诚说明还能在哪里运行

平台状态原因
Debian 特里克西✓ 在此开发和测试—
Fatdog64 / Puppy Linux 系列✓ 应该可以运行Layers 功能会自动检测以下任一项下的 union-fs 分支 /aufs （源自 Fatdog64，包括这台机器）或 /initrd （标准 Puppy）— /initrd 该路径尚未针对真实的 Puppy 安装进行测试，基于文档化的惯例而非实际验证
其他 X11 Linux 桌面✓ 应该可以运行需要 BlueZ、iptables、PulseAudio/PipeWire（带 pactl 兼容）、以及 X11 会话（不支持仅 Wayland 的桌面 — wmctrl/xdotool 需要 X11）
视窗11🧪 实验性测试版本屏幕共享、鼠标/键盘、窗口列表、音量和终端已在 Windows 上实现。该二进制文件可在自动化 CI 中构建并启动，但 尚未在真实的 Windows 机器上运行过 ——预计会有粗糙之处。蓝牙、防火墙、图层、亮度、网络和 Media Center 仍仅限 Linux，并会响应 501
macOS（Intel 和 Apple Silicon）🧪 实验性测试版本与 Windows 相同的功能集，使用 Quartz、AVFoundation 和 osascript。可在 CI 中为两种架构构建并启动，但 未在真实 Mac 上测试过。该应用未签名，macOS 将请求屏幕录制和辅助功能权限

安装网关

在您想要控制的 Debian Trixie（或兼容 Linux）机器上

# Linux — 独立二进制文件，无需安装其他任何东西 curl -LO https://github.com/cou645/trixie-gateway/releases/download/v0.2.0-test2/trixie-gateway-linux-x86_64.tar.gz tar -xzf trixie-gateway-linux-x86_64.tar.gz ./trixie-gateway --port 8772 # 然后在手机应用中：设置 → 网关 URL → http://<此机器的-tailscale-或局域网-IP>:8772 # 或者如果您们都在同一个 Tailscale 网络中，点击 "Discover Peers"

更喜欢 Python？ git clone https://github.com/cou645/trixie-gateway.git，然后 pip install -r requirements.txt 和 python3 gateway.py --port 8772。完整的安装文档，包括将其作为 systemd 服务运行，都在仓库的 README.md.

🧪 Windows 和 macOS 测试版 位于 发布页面 (trixie-gateway-windows-x86_64.exe, trixie-gateway-macos-arm64.zip, trixie-gateway-macos-x86_64.zip). 它们未签名，因此 Windows SmartScreen 会提示“未知发布者”（更多信息 → 仍要运行），而 macOS 会阻止首次启动（右键点击 → 打开）。请报告哪些地方出问题。
