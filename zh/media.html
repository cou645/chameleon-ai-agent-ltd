Chameleon Media Center

一款基于 mpv 的完整桌面媒体工作室 — 播放、播放列表、YouTube 和 Bilibili 搜索（带有即用即看缓存）、直播、DVB-T/T2 电视、DVD/蓝光/CD、蓝牙和 USB 音频路由、音效、可视化工具、视频编辑器、均衡器、虚拟网络摄像头、多手机 Android 镜像、调度程序、游戏和体育记分牌，尽在一个应用程序中。

🎞️ 由 mpv 驱动的播放 🔎 YouTube 和 Bilibili 搜索 + 观看缓存 📡 实时 DVB-T/T2/C/S/ATSC 电视 💿 DVD · 蓝光 · CD 🔵 蓝牙发送/接收 + USB 唱机/混音器输入 📱 最多同时投屏 16 部手机 📷 虚拟摄像头 + 四角画中画 📡 推流到浏览器、YouTube、Twitch 等 🤏 在每部手机上捏合/滚动缩放 ⏰ 预定录制和下载 🎮 游戏，用手机作为控制器 🤖 包含 MCP 服务器

内含功能

十三个标签页，一个媒体引擎

🎞️

视频面板

由 mpv 提供播放支持——广泛的格式支持、流畅的跳转、一键全屏切换（或 F11）、播放器进程意外终止时自动恢复，并且会记住你上次选择的音频输出设备，重启后不会重置为默认值。低延迟画中画叠加层可将最多四个摄像头——内置网络摄像头或任意手机——放置在正在播放内容的角落。一键录制正在播放的流，或下载正在播放的内容。在 Intel 显卡上，它会在 GPU 上解码 H.264、HEVC、VP9 和 AV1——CPU 占用约减少 40%，播放更流畅、电池续航更长——对于 GPU 无法处理的格式会自动回退到软件解码。

📃

播放列表

拖放重新排序、队列管理、播放列表导入和保存，以及从回收站恢复已删除的播放列表。可添加单个文件或整个文件夹（含子文件夹）。文件不存在的条目 — 未插入的 USB 驱动器、你已清理的缓存视频 — 会变灰直到文件恢复，而已清理的视频双击即可重新下载。

🔀

可互换面板

把视频放到你需要的位置。视图 → 视频 ⇄ 播放列表（Ctrl+Shift+P）将视频移到右列的顶部，并将播放列表移到左侧，在那里可以折叠，让 ADB 手机获得左列的全部高度；视频 ⇄ 观看列表（Ctrl+Shift+W）则将视频放在播放列表下方。切换过程中播放会继续进行，你选择的布局会被记住，并且全屏在所有布局中都可用。

🔎

搜索与观看缓存

搜索 YouTube 或 Bilibili，列出 TikTok 创作者的最新视频，或粘贴 TikTok、Instagram、Facebook、Snapchat Spotlight 或抖音链接。将结果排队到播放列表下方的编号观看列表中。你观看的任何内容都会在观看时保存到磁盘——无需单独下载——因此下次观看会从本地副本播放，部分观看的视频会显示已保存的进度，并在下次补齐剩余部分。将已保存的视频移到主播放列表，并在关闭应用时选择要保留或删除哪些视频。可选的浏览器 cookie 可绕过“确认你不是机器人”和登录墙。勾选“压缩下载”后，每个完成的下载或录制都会在 GPU 上重新编码为最高 720p 的 HEVC——通常约为原始大小的三分之一——如果结果不会更小则保留原始文件。

📡

DVB 电视

扫描并观看真正的数字电视 — DVB-T/T2、DVB-C、DVB-S/S2 和 ATSC — 直接来自 USB 或 PCI 调谐器。

💿

DVD / CD / 蓝光

自动检测光驱中的内容并播放 DVD-Video、蓝光或音频 CD 曲目 — 无需单独的碟片软件。

🔵

BT/USB 音频

将播放路由到一个或多个蓝牙扬声器（PulseAudio combine-sink），将适配器切换为接收模式，使 PC 本身成为蓝牙扬声器，或接入 任何 其他 PulseAudio 采集源 — USB 唱机、MiniDisc 播放器、DJ 混音器/控制器或音频接口 — 直接进入播放和可视化器，全部通过一个输入源清单完成。

📱

ADB 手机 — 最多同时 16 台

一个由 1–16 个独立面板组成的网格，列数随你喜好——可同时镜像和控制同样数量的 Android 手机，每台都有自己的屏幕、音频路由和输入。双指捏合（此设备有触摸屏）或滚轮可放大任意手机的屏幕，Shift+拖动可平移。直接用鼠标、触控笔、触摸或物理键盘进行点击、滑动和输入——每台设备持久的 shell 让每次输入都实时进行，而不必为每次按键付出新建连接的开销。一键“无线连接”会自动将 USB 连接的手机切换到 adb-over-wifi，或通过扫描手机的配对二维码进行 Wi-Fi 配对。向任意手机推送和拉取文件，休眠的手机会在开始串流前被唤醒。镜像以低延迟运行——手机的屏幕在可用时于 GPU 上解码和缩放——并且每个面板都有 A/V 同步控制，可将手机的 PC 音频延迟恰到好处的毫秒数，使声音和画面同步。息屏会在你继续从 PC 观看和控制手机时关闭手机自身的显示，关闭应用会干净地将每台手机的音视频恢复正常。

📷

虚拟摄像头

一个“CMC PC Webcam”设备，任何视频通话应用、浏览器或 OBS 都可以选择 — 向它提供内置摄像头或任何已连接手机的摄像头，并在通话中切换源而不会让应用丢失设备。每个手机面板也都有自己的虚拟摄像头。

📡

直播

将摄像头或视频面板串流到局域网或 Tailscale 上的任意浏览器（HLS 播放器页面），并为 TrXi-Ctrl、VLC 或 mpv 提供低延迟流——一次编码即可供众多观看者——或将其推送到 YouTube Live、Facebook Live、Twitch、微信视频号或任意 RTMP 服务器。在 Intel 显卡上，流会在 GPU 上编码而不是 CPU。

🔗

分享与发现

同一网络上的 CMC 会自动找到彼此，群组代码可将您的播放列表 — 包括本地文件 — 分享给其他 CMC。

🔔

音效

音板，可在您玩游戏或直播时提供动态音频提示，包括游戏中使用的足球踢球、进球欢呼和人群声音。

🌈

可视化器

为当前播放的任何内容提供实时音频响应视觉效果。

✂️

视频编辑器

帧精确的视频编辑器：按帧号或从播放帧设置入点和出点，然后剪切（保留一部分，或将其删除并加入其余部分）。从笔记和声音中添加视频、图像、标题卡，然后将它们拖入具有十四种过渡的顺序 - 交叉淡入淡出、浸入黑色或白色、溶解、擦除、幻灯片、光圈、缩放和模糊；开始或结束时的过渡会从黑色淡入或淡出。编辑时，剪辑列表位于观看列表位置的视频旁边。

手机镜头按剪辑进行处理：转动侧面显示的剪辑，并通过稳定功能消除相机抖动。混合三个音轨——剪辑自己的声音、音乐和音效——每个音轨都有自己的音量和您在预览中直接塑造的音量图。字幕已烧录或可切换；撤消和重做。

工作会在您离开时保存，并在您重新打开应用程序时返回；将其保存为项目文件夹 - 每个剪辑都用备用帧复制出来以供重新修剪，加上其图片、音乐和声音 - 稍后再次打开它，而不包含原始视频。导出在 GPU 硬件编码器（如果可用）的后台运行，并且可以将完成的视频缩小为紧凑的 HEVC 文件。

在幕后，编辑器运行自己的 FFmpeg 9 版本，针对其运行的机器进行编译，并渲染片段中的连接（每个剪辑和每个过渡），因此无论项目持续多久，内存都保持在 1 GB 以内：曾经耗尽内存的长达一小时的 33 个剪辑电影现在可以一次性连接。每个剪辑都完全在 GPU（VAAPI 和 Vulkan）上进行解码、直立、裁剪、缩放和模糊填充，用十分之一的 CPU 速度提高三到四倍，同时在 CPU 上对过渡进行交叉淡入淡出；然后将各个片段连接起来，无需重新编码，帧精确且与声音同步。保存项目时，会直接从最近的关键帧复制视频中的每个剪辑 - 几秒钟而不是几分钟，且不会造成质量损失。

⏰

日程

设置一周中某个时间和几天的作业，或者一次：播放文件或流、停止、录制流或 DVB 频道几分钟、抓取 YouTube 搜索的热门结果、仅从频道或播放列表下载新视频、仅在有物体移动时录制网络摄像头（每个事件前后几秒钟），或运行任何命令。作业在 CMC 打开时运行，并且 CMC 可以在作业时间关闭时自行启动。每个作业都可以通过 Tailscale 退出节点，以获得仅在另一个国家/地区可用的源。

🧩

插件

在 X11 上或使用 mpvpaper 在 Wayland 上播放视频作为桌面壁纸（当前视频或任何文件）。 “插件”选项卡还列出了其他作者提供的可选附加功能，例如一个视频中的几个 A-B 循环部分、其许可证、获取它们的链接以及是否已安装。没有任何第三方捆绑。

🎮

游戏

“游戏”选项卡包含棋盘、纸牌和桌面游戏，可在您的媒体持续运行时进行游戏：国际象棋、西洋双陆棋、围棋、克朗代克纸牌、麻将纸牌、战舰、井字棋、方块（点和框）、骰子和Bounty Heist Football。按照您选择的级别（Stockfish 玩国际象棋，GNU Go 玩围棋）、两个人在一个屏幕上玩，或者通过网络与朋友玩。每场比赛都会记录你的分数。回合制游戏也可以通过远程桌面在任何地方玩 TrXi-Ctrl。对于实时游戏，手机成为控制器：任意数量的运行 TrXi-Ctrl 的手机通过 Wi-Fi 或 USB 电缆连接，每个手机都有操纵杆、按钮、开球和暂停、实时比分和振动。

记分牌

大型、触摸式记分板，适用于真实比赛，按照每种运动项目各自的规则进行计分：乒乓球、羽毛球、壁球、排球、网球、飞镖、台球、斯诺克、足球、曲棍球、橄榄球、篮球等，以及任何 2-8 支球队的比赛。对于桌子上的玩家来说，数字也可以颠倒显示。还有一个国际象棋时钟、一个带圈数的秒表和一个计时器。

🎚️

18 段均衡器与音频/视频效果

用可调整并保存的预设让声音适应房间或氛围——外加音频效果和专门的视频效果选项卡。

✅

笔记

在媒体旁边直接输入或手写笔记（支持触控笔/触摸）——适合在工作时记录制作/会话笔记。

🔒

锁定、主题与偏好设置

用图案锁定窗口（Ctrl+Alt+L），切换主题并设置偏好——内置“关于”和“帮助”。

📲

远程控制

每个播放/暂停/跳转/音量操作都通过 mpv 自带的 IPC 套接字公开， TrXi-Ctrl ——我们的免费手机应用——直接与其通信，实现真正的播放控制，而不仅仅是会话列表。从手机关闭会话会干净地关闭整个应用，而不是留下一个半死不活的播放器。

🤖

MCP 服务器

捆绑的 Model Context Protocol 服务器将播放状态、播放/暂停/跳转/音量/打开和媒体库浏览作为工具公开——因此 AI 代理和您的手机始终看到并控制同一个会话。

建立在开放基础之上

PySide6 (Qt) 桌面应用，mpv 播放引擎

🖼️

PySide6 / Qt

原生、响应迅速的桌面 UI——与其余 Chameleon AI 桌面应用属于同一个 Python/Qt 技术栈。

🎬

mpv 引擎

通过 mpv 自有的窗口嵌入和 JSON IPC 套接字嵌入——这是许多 Linux 媒体工具背后同样可靠、广泛使用的播放引擎，并且已链接 libdvdnav/libdvdread/libcdio/libbluray 以支持光盘播放。

🔊

原生 PulseAudio 音频路由

多设备输出使用 PulseAudio 自有的 module-combine-sink；任何采集源——蓝牙接收或 USB 音频设备——都通过 module-loopback 环回接入，先检查 PulseAudio 自身蓝牙策略已设置好的路由，而不是与之对抗。
