Chameleon Media Center

基于 mpv 构建的完整桌面媒体工作室——播放、播放列表、带随看随缓存功能的 YouTube 和 Bilibili 搜索、直播、DVB-T/T2 电视、DVD/Blu-ray/CD、蓝牙和 USB 音频路由、音效、可视化器、视频编辑器、均衡器、虚拟网络摄像头以及多手机 Android 投屏，集于一个应用中。

🎞️ 由 mpv 驱动的播放 🔎 YouTube 和 Bilibili 搜索 + 观看缓存 📡 实时 DVB-T/T2/C/S/ATSC 电视 💿 DVD · 蓝光 · CD 🔵 蓝牙发送/接收 + USB 唱机/混音器输入 📱 最多同时投屏 16 部手机 📷 虚拟摄像头 + 四角画中画 📡 推流到浏览器、YouTube、Twitch 等 🤏 在每部手机上捏合/滚动缩放 🤖 包含 MCP 服务器

内含功能

十三个标签页，一个媒体引擎

🎞️

视频面板

播放由 mpv 驱动 — 支持多种格式、流畅跳转、一键全屏切换（或 F11）、播放器进程意外终止时自动恢复，并且会记住你上次选择的音频输出设备，重启后不会重置为默认值。低延迟画中画叠加可将最多四个摄像头 — 内置摄像头或任意手机 — 放在正在播放内容的四角。一键录制正在播放的流，或下载正在播放的内容。

📃

播放列表

拖放重新排序、队列管理、播放列表导入和保存，以及从回收站恢复已删除的播放列表。可添加单个文件或整个文件夹（含子文件夹）。文件不存在的条目 — 未插入的 USB 驱动器、你已清理的缓存视频 — 会变灰直到文件恢复，而已清理的视频双击即可重新下载。

🔎

搜索与观看缓存

搜索 YouTube 或哔哩哔哩，列出 TikTok 创作者的最新视频，或粘贴 TikTok、Instagram、Facebook、Snapchat Spotlight 或抖音链接。结果会排队到播放列表下方的编号观看列表中。你观看的任何内容都会在观看时保存到磁盘 — 无需单独下载 — 因此下次观看会从本地副本播放，部分观看的视频会显示已保存的进度，并在下次补齐剩余部分。将已保存的视频移到主播放列表，并在关闭应用时选择保留或删除哪些视频。可选的浏览器 cookie 可绕过“确认你不是机器人”和登录墙。

📡

DVB 电视

扫描并观看真正的数字电视 — DVB-T/T2、DVB-C、DVB-S/S2 和 ATSC — 直接来自 USB 或 PCI 调谐器。

💿

DVD / CD / 蓝光

自动检测光驱中的内容并播放 DVD-Video、蓝光或音频 CD 曲目 — 无需单独的碟片软件。

🔵

BT/USB 音频

将播放路由到一个或多个蓝牙扬声器（PulseAudio combine-sink），将适配器切换为接收模式，使 PC 本身成为蓝牙扬声器，或接入 任何 其他 PulseAudio 采集源 — USB 唱机、MiniDisc 播放器、DJ 混音器/控制器或音频接口 — 直接进入播放和可视化器，全部通过一个输入源清单完成。

📱

ADB 手机 — 最多同时 16 台

一个由 1–16 个独立面板组成的网格，列数随您喜欢 — 同时镜像和控制这么多 Android 手机，每台都有自己的屏幕、音频路由和输入。双指捏合（此设备有触摸屏）或滚轮可缩放任意手机屏幕，Shift+拖动可平移。直接用鼠标、触控笔、触摸或物理键盘点击、滑动和输入 — 每台设备的持久 shell 让每次输入都实时进行，而不必为每次按键付出新的连接开销。一键“无线连接”会自动将 USB 连接的手机切换为 adb-over-wifi，或通过扫描手机的配对二维码进行 Wi-Fi 配对。向任意手机推送和拉取文件，休眠的手机在开始串流前会被唤醒。

📷

虚拟摄像头

一个“CMC PC Webcam”设备，任何视频通话应用、浏览器或 OBS 都可以选择 — 向它提供内置摄像头或任何已连接手机的摄像头，并在通话中切换源而不会让应用丢失设备。每个手机面板也都有自己的虚拟摄像头。

📡

直播

将摄像头或视频面板串流到您局域网或 Tailscale 上的任何浏览器（HLS 播放器页面），并为 TrXi-Ctrl、VLC 或 mpv 提供低延迟流 — 一次编码即可供众多观看者 — 或推送到 YouTube Live、Facebook Live、Twitch、微信视频号或任何 RTMP 服务器。

🔗

分享与发现

同一网络上的 CMC 会自动找到彼此，群组代码可将您的播放列表 — 包括本地文件 — 分享给其他 CMC。

🔔

音效

用于在游戏或直播时即时播放音频提示的音板。

🌈

可视化器

为当前播放的任何内容提供实时音频响应视觉效果。

✂️

视频编辑器

帧精确的片段序列器：从播放器设置入点/出点帧，重新排列片段，添加音乐轨道（混音在原始声音之下或替换原始声音）和字幕（烧录或作为可切换轨道），然后在后台导出。

🎚️

18 段均衡器与音频/视频效果

用可调整并保存的预设让声音适应房间或氛围——外加音频效果和专门的视频效果选项卡。

✅

笔记

在媒体旁边直接输入或手写笔记（支持触控笔/触摸）——适合在工作时记录制作/会话笔记。

🔒

锁定、主题与偏好设置

用图案锁定窗口（Ctrl+Alt+L），切换主题并设置偏好——内置“关于”和“帮助”。

📲

远程控制

每个播放/暂停/跳转/音量操作都通过 mpv 自带的 IPC 套接字公开， TrXi-Ctrl ——我们的免费手机应用——直接与其通信，实现真正的播放控制，而不仅仅是会话列表。从手机关闭会话会干净地关闭整个应用，而不是留下一个半死不活的播放器。

🤖

MCP 服务器

捆绑的 Model Context Protocol 服务器将播放状态、播放/暂停/跳转/音量/打开和媒体库浏览作为工具公开——因此 AI 代理和您的手机始终看到并控制同一个会话。

建立在开放基础之上

PySide6 (Qt) 桌面应用，mpv 播放引擎

🖼️

PySide6 / Qt

原生、响应迅速的桌面 UI——与其余 Chameleon AI 桌面应用属于同一个 Python/Qt 技术栈。

🎬

mpv 引擎

通过 mpv 自有的窗口嵌入和 JSON IPC 套接字嵌入——这是许多 Linux 媒体工具背后同样可靠、广泛使用的播放引擎，并且已链接 libdvdnav/libdvdread/libcdio/libbluray 以支持光盘播放。

🔊

原生 PulseAudio 音频路由

多设备输出使用 PulseAudio 自有的 module-combine-sink；任何采集源——蓝牙接收或 USB 音频设备——都通过 module-loopback 环回接入，先检查 PulseAudio 自身蓝牙策略已设置好的路由，而不是与之对抗。
