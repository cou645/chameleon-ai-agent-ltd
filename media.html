Chameleon Media Center

A full desktop media studio built on mpv — playback, playlists, live streaming, DVB-T/T2 TV, DVD/Blu-ray/CD, Bluetooth & USB audio routing, sound effects, a visualizer, a video editor, an equalizer, and triple Android phone mirroring, in one app.

🎞️ mpv-powered playback 📡 Live DVB-T/T2/C/S/ATSC TV 💿 DVD · Blu-ray · CD 🔵 Bluetooth Tx/Rx + USB turntable/mixer input 📱📱📱 Three phones mirrored at once 🤏 Pinch/scroll zoom on each phone 🤖 MCP server included

What's inside

Fourteen tabs, one media engine

🎞️

Video panel

Playback powered by mpv — wide format support, smooth seeking, a one-click fullscreen toggle (or F11), and automatic recovery if the player process ever dies unexpectedly.

📃

Playlist

Drag-and-drop reordering, queue management, quick access to what's next.

📡

DVB TV

Scan and watch real digital TV — DVB-T/T2, DVB-C, DVB-S/S2 and ATSC — straight from a USB or PCI tuner.

💿

DVD / CD / Blu-ray

Detects what's in the optical drive automatically and plays DVD-Video, Blu-ray or Audio CD tracks — no separate disc software needed.

🔵

BT/USB audio

Route playback to one or several Bluetooth speakers at once (PulseAudio combine-sink), flip the adapter into receive mode so the PC itself becomes a Bluetooth speaker, or loop in any other PulseAudio capture source — a USB turntable, MiniDisc deck, DJ mixer/controller, or audio interface — straight into playback and the Visualizer, all from one Input Sources checklist.

📱📱📱

ADB Phone — three at once

Three independent panels side by side — mirror and control three Android phones simultaneously, each with its own screen, audio routing and input. Pinch (this box has a touchscreen) or scroll-wheel to zoom into any phone's screen, Shift+drag to pan. One-click "Connect Wireless" switches a USB-connected phone to adb-over-wifi automatically.

📡

Live Stream

Pull in a live stream alongside a built-in Sound Effects board for on-the-fly audio cues.

🌈

Visualizer

Real-time audio-reactive visuals for anything currently playing.

✂️

Video editor

Trim, cut and assemble clips without leaving the app.

🎚️

18-band equalizer & audio/video effects

Shape the sound to the room, or the mood — plus a dedicated video effects tab.

✅

Notes

Typed or handwritten notes (stylus/touch-friendly) right alongside your media — useful for production/session notes while you work.

📲

Remote control

Every play/pause/seek/volume action is exposed over mpv's own IPC socket, which TrXi-Ctrl — our free phone app — talks to directly for real transport control, not just a session list. Closing a session from the phone closes the whole app cleanly rather than leaving a half-dead player behind.

🤖

MCP server

A bundled Model Context Protocol server exposes playback status, play/pause/seek/volume/open and library browsing as tools — so an AI agent and your phone always see and control the same session.

Built on open foundations

PySide6 (Qt) desktop app, mpv playback engine

🖼️

PySide6 / Qt

A native, responsive desktop UI — part of the same Python/Qt stack as the rest of the Chameleon AI desktop apps.

🎬

mpv engine

Embedded via mpv's own window-embedding and JSON IPC socket — the same reliable, widely-used playback engine behind many Linux media tools, with libdvdnav/libdvdread/libcdio/libbluray already linked in for disc playback.

🔊

PulseAudio-native audio routing

Multi-device output uses PulseAudio's own module-combine-sink; any capture source — Bluetooth receive or a USB audio device — loops in via module-loopback, checking first for routing PulseAudio's own Bluetooth policy already set up rather than fighting it.
