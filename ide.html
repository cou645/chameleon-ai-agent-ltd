Chameleon AI IDE

A code editor where the AI does the work — it reads your files, makes the edits, runs the commands and checks the result. You review and approve.

🧠 AI edits your code directly 🎙️ Voice in, spoken answers 🔀 See a diff before you accept 🔌 Nine AI providers, swap anytime 🔒 Runs local, keys stay yours

What makes it different

Most AI editors suggest. This one operates the editor.

🤖

The AI makes the edits

It reads a file once, then makes as many precise changes as needed without re-reading. Edits target exact text, not line numbers, so they don't drift as the file changes. New files are written whole — with an automatic backup of anything it replaces.

💻

It runs commands and reads the results

The AI runs shell commands in the built-in terminal, waits for each result, checks the exit code, and decides what to do next. Real work in a live shell — not copy-paste snippets.

🛡️

Safe by default

Everything the AI reads from a file, a terminal or a web page is fenced off as data, never as instructions — a malicious file can't hijack the session. Every change it makes is logged with a timestamp and session ID, so you have a full history of what happened.

🔀

Review before you accept

One click shows a colour-coded diff of the AI's changes against your last save. Accept them, keep editing, or back out.

🎙️

Hands-free

Dictate a question or a whole prompt with on-device speech-to-text, and have answers read back in a natural voice. Nothing goes to a cloud transcription service.

🔌

Bring your own AI

DeepSeek, OpenAI, Claude, Groq, Mistral, Kimi — switch provider in the middle of a project. Run a model locally through Ollama or LM Studio for no cost at all. Claude Code runs as a live process right inside the terminal.

🧩

Stackable working modes

Turn on the modes you need — code repair, academic writing, plain chat — and combine them. A running cost estimate shows before you send anything.

🗂️

A real editor underneath

Multi-tab editing with per-tab undo and syntax highlighting, a project file tree, and streaming chat that keeps the window responsive while commands run in the background.
